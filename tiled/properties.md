# Tiled のタイルに付けるプロパティ

## この文書について

**地図を描く人のための、プロパティ名の一覧です。** **`engine/tiled.go` が読む語の正はここ**で、**ルールの中身は `NODE.md`、数値は `PARAMETERS.md`、起動の仕方は `README.md` の `-tiled`、これから増える語の設計は `PLAN.md` の「地図を作者に開く」P16-5**（決定事項#133）にあります。

**語を足したり意味を変えたりしたら、この表を上書きします**（経緯は `HISTORY.md`）。

## レイヤーの決まり

- **最初のタイル層が地形。** これだけは順番で決まります。
- **そのあとのタイル層は、順番ではなく中身で決まります**——`region` を持つタイルで塗ってあれば地域、`spawn` を持つタイルで塗ってあれば発生タイル。**どちらも持たない装飾レイヤーは無視される**ので、何枚足しても構いません。
- **オブジェクト層の矩形も地域です**（同じプロパティを持てる）。**同じセルについて塗りと矩形の両方が言っていたら、塗りが勝ちます。**
- **非表示（visible = 0）のタイル層は読み飛ばされます。** **地域レイヤーを消して地形を見たいときは、非表示ではなく不透明度（opacity）を下げてください**——不透明度は読まないので影響しません。**地形レイヤーを隠すと、2枚目が地形として読まれます。**

## 今 engine が読む語

| 層 | プロパティ | 型 | 値 |
|---|---|---|---|
| 地形 | `kind` | string | `flat` / `rough` / `water` / `high` / `slope`（省略・空は `flat`） |
| | `height` | int | 1〜9。`high` / `slope` のとき。省略は1 |
| 発生 | `spawn` | string | `plant` / `fish` / `enemy` / `food`（植物と魚）/ `all` / `none` |
| 地域 | `region` | string | 地域の名前。**同じ名前のタイルは離れて塗っても1つの地域** |
| | `shelter` | float | 休息の守られ具合。0〜2。**0 は「世界の乱数任せ」** |
| | `food` | float | 植物の生えやすさ。0〜2。0 は乱数任せ |
| | `special` | float | 「手のかかる作物」の割合。0〜2。0 は乱数任せ |
| | `enemies` | float | 外敵の湧きやすさ。0〜2。0 は乱数任せ |
| | `goal` | bool | ゴールエリアの印。**engine は1度も読まない**（`World.GoalRegions()` で取り出すだけ。判定はゲーム側） |
| 豊かさ | `rich` | float | **そのセルがどれだけ食料を育てるか**（0〜2。**1が普通**、0は不毛）。**発生タイルと同じタイルに付けてよい** |
| 外敵の種類 | `enemy` | string | **そのセルに来る外敵の種類**（名前。`Config.EnemyKinds[].Name` と一致させます。**魚もこれ**）。**「どの種類が来るか」は `Share`、塗りが決めるのは「どこに」**。**塗っていない種類は今までどおり湧きます** |
| 天気 | `chill` | int | **そのセルの寒さ**（1〜9。**9が一番寒い**。0 と未指定は常温）。**割合であって用量ではありません**——**一番寒い所が1tickにいくら取るかは `Config.ChillDrain`**（決定#133）。**専用のレイヤーに塗るのが普通ですが、engine はレイヤーの名前も番号も見ません** |
| | `heat` | int | **そのセルの暑さ**（1〜9。用量は `Config.HeatDrain`）。**1つのタイルは寒いか暑いかのどちらかです**（両方書くと `chill` が勝ちます） |
| 巣 | `rate` | float | **その巣からどれだけ湧くか**（0〜2。**1が普通、0は「ここからは来ない」**）。**率ではなく取り分**——**1tickに何体来るかは `EnemySpawnTicks`、世界の上限は `MaxEnemies` のまま**で、**塗りが決めるのは「どの巣から出るか」だけ**（2026-09-22）。**`enemy` を付けたタイルと同じタイルに付けます** |
| | `cap` | float | **その巣が自分の `Roam` の中に何体まで抱えるか**（`Config.NestCap` の何倍か。0〜2。**0 は「ここは誰も抱えない」＝そこからは湧かない**）。**満ちている巣は外から入れないだけで、生まれるほうは止めません**。**`Config.NestCap` が 0 の世界では定員そのものがありません**（2026-09-22） |
| 植物の種類 | `plant` | string | **そのセルがどの種類の植物を育てるか**（名前。**`Config.PlantKinds` の行を指すだけで、数値は地図に置きません**）。**発生タイルと同じタイルに付けてよい**。**塗っていないセルは種類の抽選になります** |

**プロパティを1つも持たないタイルと、空セルは、高さ0の平地です。**

## 高さが絵を決める（2026-09-22。engine ではなくビューアの読み）

**`height` は engine にとっては「段」でしかありません**（1段までしか上り下りできない＝`canStep`）。**絵のほうは、同じ数から「そこが何であるか」も読みます**（`cmd/devview/ground.go`）。**規則を1つも足していません**——**高さ3に登るには高さ1・2・3の坂を3枚並べる必要があり、誰も並べない**ので、**登れない段は最初から壁だった**という読みです。

| `height` | 描かれ方 | 意味 |
|---|---|---|
| 0 | 森の床（`kind: rough` なら荒れ地）。**暗い** | 平地 |
| 1〜2 | **登れる高台の面＋岩の縁**。**明るい** | 坂を隣に置けば上がれる |
| 3〜4 | **巨木の幹＋根の縁** | 登れない。何マスかまとめて塗る |
| 5以上 | **巨岩＋岩の縁** | 同じく登れない |

**塊（巨木・巨岩）は3×3以上で塗ってください。** **2×2だと4マス全部が縁になり、面が1マスも出ません**（根や落石の輪だけになる）。**幹は縦に描かれている**ので、**横に広く・縦に浅い塊のほうが綺麗に出ます。**

**明るさは2段階しかありません**——**暗い＝世界の床、明るい＝登れる台地**。**2段目の台地が1段目より明るいということはなく**、**何段あるかは段差の線（越えられない辺だけに引かれる）が言います。**

**坂の向きは地図が決めます**——**engine は向きを持ちません**が、**ビューアは「隣のどちらが高いか」で段の絵を回します**。**どちらとも言えないセルには、向きの無い坂が出ます。**

## 将来のために予約する語

**今は黙って無視されます**（エラーになりません）。**今日から書いておけば、実装した日に意味を持ちます。** 設計は `PLAN.md` の P16-5。（**`rich` / `plant` / `enemy` は 2026-09-20 に実装され、上の表へ移りました。**）

| プロパティ | 型 | 意味 | 実装予定 |
|---|---|---|---|
| `nest` | bool | この地点が巣であること。**実装しませんでした**——**巣は `enemy` を塗ったセルそのもの**（2026-09-20）で、**どれだけ湧くか・何体抱えるかは `rate` と `cap`**（2026-09-22。上の表）。**作者の目印として書くのは自由で、engine は無視します** | — |
| `roam` | float | 巣からの徘徊半径。**数は地図に置かない**（#133）ので、**半径は `EnemyKind.Roam`**（`Config` の行）です。**engine はまだこの語を読みません** | — |
| `human` | string | そのセルに置く**人間の巣**の名前（`Config.HumanNests` の行を指すだけ。数値は地図に置きません） | P16-8 |

**巣の数字は `rate` と `cap` で言います**（2026-09-22）。**どちらも `enemy` を塗ったタイルに付け、比だけを運びます**——**`rate: 1.8` は「普通の巣の1.8倍の取り分」、`cap: 0.4` は「`Config.NestCap` の0.4倍」**。**絶対の数は `Config` にあります**（決定#133）。

**巣の色板は `nest.tsx` です**（2026-09-22 に `enemy_nest` から改名し、人間の巣を4枚足して8枚になりました）。**前半4枚が外敵の巣**（`enemy` ＋ `nest` ＋ `roam` ＋ `spawn: enemy`。丸）、**後半4枚が人間の巣**（`human` ＋ `nest`。四角＝**丸と見分けるため**）。**人間の巣に `spawn` は付けません**——**`spawn` の語彙は plant / fish / enemy / food / all / none で、人間は入っていません**（人間は発生タイルではなく巣そのものから湧きます）。**名前は `hearth` / `haven` / `camp` / `landing` の4つ**で、**`Config.HumanNests` の行と一致させます**（地図が運ぶのは名前と場所だけ）。

**魚は外敵の一種です。** **種類の表は「植物」と「外敵」の2つだけ**で、**水の生き物は `EnemyKinds` の `Water` の行**（`cmd/devview -lurkers` がその例）。**`fish` という種類名の語はありません。**

**`spawn: fish` はこれとは別のものです。** **あれは「食料アイテムの魚が湧く場所」**であって、生き物の話ではありません。**水に湧く生き物を置きたいなら `spawn: enemy` ＋ `enemy: <水の種類の名前>`。**

**種類の中身**（予算・移動能力・栄養・ドロップ）**は地図に書きません。** **タイルが持つのは名前1つで、数値は `Config` の表**（`EnemyKinds`、将来の `PlantKinds`）にあります——**両方に置くと必ず片方が古くなるため**（決定事項#133）。

## 名前の衝突

- **`kind` は地形専用です。** 植物や外敵の名前に使うと、**地図全体が読み込みエラーになります**:
  `tiled: tile 10: kind "berry" is not one of flat, rough, water, high, slope`
- **`food` は地域の豊かさで予約済みです。** 食べ物の種類名には使わないでください。
- **知らない名前のプロパティは無視されます。** 作者が自分のメモを付けるぶんには自由です。
- **数値のプロパティを「文字列」型で書いても読めます**（2026-09-20 に対応）。Tiled はプロパティの型を選ばせるので、**数値のつもりで string を選ぶのは起きやすく、しかも気づけません**——**以前は0として読まれ、`height: "3"` のタイルが黙って高さ1になりました**。**数値でない文字列を `height` に書いた場合はエラーになります**（黙って0にはしません）。

## Tiled 側の決まり

- **`.tmj`（JSON）で保存する。** **`.tmx`（XML）は読めません。**
- **タイル層は CSV か非圧縮で保存する**（圧縮したものは読めません）。
- **タイルセットは地図に埋め込む**（Map > Embed tileset）。**別ファイルの `.tsx` は拒否されます**——engine はファイルを読まないため。
- **無限マップ（infinite）にしない。**
- **プロパティは素の「カスタムプロパティ」で付ける。** **タイルの「クラス（Class / Type）」は使わないでください**——engine は読みませんし、クラスのメンバーは既定値と同じだと JSON に書き出されないことがあります。
- 埋め込みタイルセットのタイルを編集するには、**タイルセットパネルのスパナ（Edit Tileset）** で開きます。**複数タイルを選んで一括でプロパティを付けられます。**

## 描くときの落とし穴

- **高地は「登れない壁」であって「入れない壁」ではありません。** 高さの違うセルの間は、**高いほうが `slope` のときだけ**通れます。**初期配置は地形を見ない**ので、ランプの無い高地に生まれた個体は降りられません（サンプルでは9セルが該当し、**16シードの平均で70体中1.1体**がそこに生まれます）。壁が欲しいなら `rough` か `water` にするほうが安全です——**ランプのある高地なら閉じ込めにはなりません**（降りられるので）。
- **水に高さはありません**（`water` は必ず高さ0）。**台地の内側に水を置くと、出入りできない池になります。**
- **高さの差が2以上あるセルの間は、どうやっても通れません。**
- **地域を塗り残したセルは、「それ以外の場所」という1つの地域**になります（その図は世界の乱数任せ）。3分割のつもりなら、塗り残しがないか確かめてください。
- **発生タイルは「ヒント」ではなく「そこにしか湧かない」マスクです。** **量（`FoodSpawnRate`）は変わらない**ので、狭く塗るとその中に同じ量が集中します。
- **`rich` は細かく塗るほど効かなくなります。** **視界（130）より小さい区画は居場所を動かしません**——実測で、世界を48区画・108区画に切ると「人が立っている地面の豊かさ」が半分になり、48と108は区別がつきませんでした。**豊かな場所を作りたいなら、視界より大きく塗ってください**（既定の地域は 200×200 ＝ 視界の1.5倍）。
- **`rich` を1枚でも塗ると、世界の側の重み付けは止まります**（`FoodSpread`・地形との相関・水辺）。**作者が言ったことに、世界が二つ目の答えを足さないため**です。
- **届かない場所は食料を飲み込みます。** **世界に同時に在る植物の数には上限があり**（`MaxFoodItems`）、**ランプの無い高地に生えた植物は誰にも食べられないまま枠を占め続けます**。**その割合は時間とともに増える**ので、**じわじわ全員が餓死します**。サンプルの地形で実測（シード1）: **発生タイルを塗らないと、届かない高地と水の上に植物の 23% が溜まり、個体数が 56 → 18 に落ちます**。**発生タイルを陸だけに塗れば 0% のまま、個体数は 60 → 99 に伸びます**。**対策は2つ——発生タイルで陸だけに塗るか、高地にランプを付けるか。**
- **陸に塗った魚は無視されます**（refuse ではなく ignore）。

## サンプル

`samples/001_3division.tmj` —— 30×20、川と中央台地で3分割した地図。

**`rich` は地域タイルに載せてあります**——**1枚のタイルが「どの地域か」と「どれだけ育つか」を同時に言っている**例です（西 1.6 / 北東 0.6 / 南東 1.0）。**塗りのまとまりは 14×20・14×9・14×11 セル**で、**視界（130 ＝ この地図で約5セル）よりはるかに大きい**——**これが効く塗り方**です。**発生タイルの1セルずつに `rich` を振っても効きません**（視界より小さいので、どこに立っても複数のセルが視界に入り、平均に均される）。

**実測**（12シード × 20000tick）: **平均個体数は 87.1 → 87.2 と変わらず**（総量保存）、**西半分に立つ割合が 0.61 → 0.73 に動きます**。**「どれだけ」ではなく「どこに」が変わる**、という `rich` の性質がそのまま出ます。**上の語を一通り使っています**（地形5種・発生3種・巣・地域3つと `goal`・将来用の `plant` / `enemy` / `nest` / `roam` / `rich`）。

```
go run ./cmd/devview -tiled tiled/samples/001_3division.tmj
```

`samples/002_forest.tmj` —— 30×20、**描かれた地形のタイルセットで描いた地図**（2026-09-22）。川・荒れ地・2段の台地と坂・巨木2本（3×3）・巨岩（2×2）。**上の「高さが絵を決める」を一通り使っています。**

```
go run ./cmd/devview -tiled tiled/samples/002_forest.tmj
```

## 地形のタイルセット

**`samples/tilesets/002_mononoke/`**（2026-09-22）——**ゲームで実際に貼られる絵そのもの**の8タイル。Tiled では「外部タイルセットを追加」で `terrain.tsj` を読み、**地図に埋め込んで保存**します（埋め込みは engine の要求）。

**取り込み方**: Tiled で **マップ > 外部タイルセットを追加**（Map > Add External Tileset）から `terrain.tsj` を選びます（**`.tsx` も同じ内容で置いてあります**——お使いの Tiled が JSON を出さない設定でも読めます）。**そのあと マップ > タイルセットを埋め込む**（Map > Embed tilesets）で地図に埋め込んでください（**埋め込みは engine の要求**で、エラーメッセージも同じことを言います）。

| id | クラス | タイル | プロパティ |
|---|---|---|---|
| 0 | field | 森の床 | `kind: flat` |
| 1 | broken | 荒れ地 | `kind: rough` |
| 2 | stream | 渓流 | `kind: water` |
| 3 | ramp 1 | 坂（床から1段目へ） | `kind: slope` / `height: 1` |
| 4 | ledge 1 | 高台1段目 | `kind: high` / `height: 1` |
| 5 | ledge 2 | 高台2段目 | `kind: high` / `height: 2` |
| 6 | tree | 巨木 | `kind: high` / `height: 3` |
| 7 | boulder | 巨岩 | `kind: high` / `height: 5` |
| 8 | ramp 2 | 坂（1段目から2段目へ） | `kind: slope` / `height: 2` |

**0〜7 は `001_simple` の色板と同じ並び**なので、**あちらで描いた地図は意味が変わりません**（8 は後ろに足したもの）。**クラス名は Tiled の画面で見分けるためのもの**で、engine は読みません。

**坂が2つあるのは、坂が「その高さと、1つ下」をつなぐものだから**です。**2段目の台地には `ramp 2` を置かないと誰も登れません**（`ramp 1` は床と1段目をつなぐだけ）。**最初に作ったタイルセットにはこれが無く、見本の地図に「誰も立てない2段目」ができていました。**

**`001_simple/` は色板のまま残してあります**（何が塗ってあるか一目で分かるので、地形だけ手早く描くときはこちらが速い）。**2026-09-22 から、こちらにも `.tsx` が4つ**（`terrain` / `region` / `food_spawn` / `nest`）**あり、プロパティは見本の地図 `001_3division.tmj` と同じ中身**です——**「外部タイルセットを追加」で読み、地図に埋め込んで保存**すれば、あの地図と同じ意味で塗れます。**2箇所に同じことが書いてあるので、テストが突き合わせます**（`TestThePaintedTilesetsSayWhatTheSampleMapSays`）。**タイルセットは絵が変わっても `pack_sprites.py --tiled` が書き直します。**

## 天気の塗り方（決定#135・2026-09-20）

**天気は地形とも地域とも別の地図で、粒度は絵そのものが決まります。** **地域が3つでも、天気は30段階置けます**（**これが地域から切り離した理由**——地域の数は難易度のつまみなので、粗い地図ほど天気も粗くなるのは設計の誤りでした）。

- **`chill` / `heat` を持つタイルを1枚作り、専用のレイヤーに塗る**のが素直です。**地形タイルが天気を兼ねても読めます**（`rich` と同じ扱い）。**engine はレイヤーの名前も番号も見ません**——**中身で決まります**（最初のタイル層だけが常に地形）。
- **色板を同梱しました**（2026-09-22。`001_simple/chill.tsx` と `heat.tsx`、**各3段**）。**寒さは 3 / 6 / 9、暑さは 3 / 6 / 9** で、**明るい半透明**なので**下の地形が透けて見えます**（塗りながら地形を確かめられる）。**段は色だけでなく印の数でも分かります**（雪の印1〜3個／しずく1〜3個）。**9段すべてが要るなら自分で足してください**——**engine の語彙は 1〜9**です。
- **1〜9 は「一番きつい所を9としたときの割合」**で、**用量は `Config.ChillDrain` / `HeatDrain`**。**同じ絵が、置かれる世界によって穏やかな冬にも殺す冬にもなります**——**初期ステージは絵を描き直さずに用量だけ下げられます**。
- **なだらかに描いても効きません。** **身体が読めるのは「隣のセルとの段の差」**で、**段は9つしかない**ので、**傾斜を細かく描くと隣同士が同じ文字になり、一歩先を読んでも同じ値が返ります**。**実測**: 世界を4列に分けた絵では東西の読みの差が 0.0278、10列で 0.0056、**40列で 0.0000**。**個体数が動いたのは4列の絵だけ**（48.4 → 94.4）。
- **つまり天気は「何セルおきに段が変わるか」で描いてください。** 段と段の間は同じ文字で埋めてよく、**段が視界の中に入る間隔で置く**のが効く塗り方です（`rich` の「視界より大きく塗る」と同じ理屈）。
- **devview で確かめる**: `go run ./cmd/devview -tiled <地図> -weather -cold 0.05`（寒さは青、暑さは琥珀の重ね塗り）。
