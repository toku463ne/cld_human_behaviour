# 外敵と戦闘

**外敵の種類と居場所、戦闘の構え、投擲。**

- **水に住む外敵（段階63、`EnemyKind.Water`）** — **既定はどの種類も持たない**（`cmd/devview -terrain river -lurkers`）: **段階59 の表に1行**で、**水のセルから湧き**（`spawnFish` と同じキャッシュ）、**水では溺れない**（**フラグ1つに意味が2つ乗るが、それは同じ1つの事実**＝川に住むものを川は取らない）。**水の無い地図では普通の種類と同じように湧く**（湧きを黙って落とすと外敵の数が黙って変わる）。**既存の食料魚には1行も触っていない**（#95。**魚は食料アイテム、これは身体**で、#78 の保留はそのまま）。**測定: 仕組みは動き、人は川から出ない**——`enemiesWet` 0.12 → 0.30 に対し **`humansWet` は 0.11 → 0.15 と逆向き**（+0.04 \*）。**これで4度目**（34 溺れる・35 覚えて伝える・63 住んで狩る はどれも動かず、動かしたのは段階36 の食料だけ）。**溺死 −4.69 \*\* は死因が排他だから**＝**獣に殺された身体は溺死に数えられない**（段階34 では逆が起きていた）

- **獣の扱いを知っている（段階62、`SkillWard` / `EnemyKind.Ward`）** — **既定はどの種類も `Ward` を持たない**: **スキルは1種類だけ足し、どの獣について知っているかは種類の行が名指しする**（**2つの種類を同じ言い伝えで防げる**。別々にするなら列挙に1行）。**形は `SkillPoison` の流用で、2つの半分が同じ数字を共有する**——**その獣の打撃から引かれるぶん**と、**その獣の近くにいることに付ける値段**（`AgentView.Ward` として知覚に載るが、**相手の攻撃力は隠しパラメータのまま**＝載るのは「自分が何を防げるか」）。**天井は防御力**（段階47 の理由づけ＝当たったとき何が起きるかを決める遺伝子が、当たるかどうかまで決めてはいけない）、**出生地の種は「その地域に、言い伝えのある獣がどれだけ湧くか」**。**測定: 仕組みは動き、世界は動かない**（保有率 0.26〜0.32、実効値 0.24、**的に届くのは人間の死の2%**）。**#94 の賭けはここで決着した**——**「命に関わる」ことが大きくするのは掛け算の3つ目の項だけ**。**そして実効値が伸びない理由は天井の遺伝子**（防御力は予算比 0.06）＝**強いスキルを作りたいなら天井は買われている遺伝子でなければならないが、役割を重ねない線があるので、買われている遺伝子ほどその役に既にスキルがある**

- **誰が何を食べられるか（段階60、`EnemyKind.CanEatPlants` / `PlantAppetite`）** — **既定は段階11 の食性のまま**: **消化できるかは種類の行**（`canEat` の1か所を通るので、食事・運搬・贈与・売買・知覚の5経路は自動）、**どれだけ食べたいかは `dietValue` の中の掛け算1つ**（**見積もりと一口が同じ倍率を通る**＝身体が自分について嘘をつかれない）。**確率のコインフリップは無い**（段階25 の2階建て。**同じ空腹で食欲1.0 なら食べ 0.25 なら食べないが、どちらでも候補には挙がる**ことをテストで固定）。**測定（48シード）: 外敵が4倍**（`enemies` 12.4 → 49.0）で**人間は −6.17 \***、`plantsToEnemy` 952（世界が生やす 4000 の24%）、`hunts` +46.98 \*\*\*、`enemyKillShare` 0.59 → 0.80、`humansByEnemy` 0.76 → 0.81。**外敵の数を決めているのは `MaxEnemies` でも `EnemySpawnTicks` でもなく餌**。**食欲4倍でも食べた量は1.9倍**＝**段階16 の飽きの割引が新しい食べ手にも効く**。**そして `pop` は2種族の合計なので、片方だけを養う規則はそれでは測れない**（`humans` / `enemies` の列を足した）

- **外敵はどこまで離れるか（段階64、`EnemyHomeCost` / `EnemyKind.Homely`）** — **既定はオフ**（0。`cmd/devview -homebound` で入れられる）: **外敵は「世界に入ってきた地域」から離れるほど高い代価を払う**（**1tickあたり、地域の幅1つぶんごとに**＝段階34 の `Hazard` と同じ形。**`Utility.Roam` として別の列にした**＝`Risk` に混ぜない。**自分の地域の中は無料**＝#53）。**`Agent.HomeRegion` は固定参照**（湧いた／生まれた地域。移住も更新もしない＝`GuardianID` と同じ立場）。**引き戻しではない**——**育児の紐と同じ形は採らない**（外敵は人間と同じ意思決定エンジンで動くので、強制は閾値そのもので、境界の際で振る舞いが不自然に切れる＝段階13 が避けた形）。**十分に良い手があれば遠くでも選ぶ**（テストで固定）。**帰り道は候補を1つ足すだけで値打ちを持たない**（全候補が「その手がどこへ連れて行くか」で課金されるので、**安いから勝つ**。**無ければ遠くの身体は全候補を等しく嫌いになるだけ**＝55a が裏側から見つけたこと）。**測定（48シード、基準は段階58 単独）: この群で唯一、狙った量が狙ったとおりに動いた**——**段階58 の湧きの偏りが初めて居場所に残り**（`prowlArrive` 0.11 のうち **6% → 45%**、`prowlGain` +0.06 \*\*\*）、**危険地帯が噛む**（`prowlBite` +0.21 \*\*\*）、距離は `enemyAway` 1.24 → 0.64・`enemyAtHome` 0.26 → 0.53。**効いているのはコストであって帰り道ではない**（`homeShare` 0.01＝決定の1%。15b の 0.05・55a の 0.07 より少ない）。**代価は外敵が獲物を見つけられなくなること**（`hunts` −56 \*\*\*、`rareShare` 0.15 → 0.10、餓死 +20 \*\*\*、`packSize` −0.38 \*\*\*）＝**外敵は肉しか食べないので、動かないことは食べないこと**。**人間には良い**（個体数 +8.94 \*、`killShare` −0.04 \*\*\*）＝**「危険地帯を作る」と「世界を穏やかにする」は同じ操作の両面**

- **外敵の種類（段階59、`EnemyKinds`、`engine/enemykind.go`）** — **既定は空＝1種類**（`cmd/devview -kinds` で2種類にできる）: **`Species` は2値のまま**で、**種類は表の1行**（段階11 が決めた「同じノード・同じ意思決定エンジン・違うのは予算の抽選範囲と食性だけ」の一般化）。**1行が持つのは4つ**——名前・湧きに占める割合・予算の範囲・**`Homing`**（段階58 の地図の重みにどれだけ従うか）。**増やすのは1行だけ**（**どの規則も行数を数えず、空欄は世界の既定に落ち、割合は正規化され、意思決定エンジンに種類の分岐は無い**。3行の世界が1行のコードも足さずに動くことをテストで固定）。**`Agent.Kind` はタグ1つ**（湧いたときに決まる固定参照＝`GuardianID` と同じ立場）。**種類は種ではない**——**求愛は種類を見ないので交配する**（実装して初めて分かった。**子の種類は予算と同じコイン**＝#2 で、**親が同じ種類なら乱数を引かない**）。**`Homing` を「種類ごとの地図」にしなかった**のは、**危険な土地は1つ**だから。**測定（48シード、対照は「同じ中身を2行に分けただけ」）**: **表は効く**（`kindGap` 1.57 対 対照 1.10＝標本の底）、**`Homing` は効かない**（+0.01 ± 0.02＝段階58 の結論どおり）、**そして混ぜ方が世界の選択を変える**（**重いのが4分の1なら殺しとパワー**＝`killRate` +0.20 \*\*・`dPower` +3.69 \*／**半分なら狩りと凝集、ただし頭の良さを払う**＝`hunts` +8.15 \*・`halfLife` +6.45 \*・`dIntelligence` −3.98 \*\*）。**`packSize` はどちらでも動かない**＝**大きい獲物は群れ狩りを呼ばない**（段階11 の結論が保たれた）。**`kindMix` の底は標本**（到着48体に対する 1/√48 ≈ 0.07）

- **外敵はどこから来るか（段階58、`EnemySpread`）** — **既定はオフ**（0。`cmd/devview -prowl` で入れられる）: **外敵の湧く地域を重みつきで引く**（`pickFoodRegion` と同型。**湧く総数は変えず位置だけを変える**＝段階15a の論法。**0 なら乱数を1つも引かない**）。**人間の湧きには効かない**（人間は出産でしか増えない）。**「危険」と呼ばないのは、その語が段階35 の信念で埋まっているから**。**測定（48シード）: 規則は完璧に発火し、世界が消す**——`prowlArrive` **+0.25 \*\*\*** に対し `prowlGain` ±0.01（**残るのは6%**）。**消える理由は2つとも数えた**: **新しい外敵の 38〜41% は世界の中で生まれる**（親のいた場所から始まるので重みが触れていない）／**出発点からの平均距離は 270 で、地域の幅は 200**。**偏らせると外敵はむしろ散る**（`enemyCrowd` −0.20 \*\*）＝**既定で固まって見えるのは人間を追っているから**。**世界の数字は動かない**（個体数 +2.08 ± 6.72、`killShare` −0.00）。**測定の作法としての収穫は「規則が発火した瞬間の効き目」と「世界に残る効き目」を別の列にしたこと**——**これが無ければ「重みが効かない」と書いて終わっていた**。**段階64（湧いた地域から離れるコスト）は「危険地帯」の付け足しではなく前提**

- **投げるのが上手い（段階47、`SkillThrow`）** — **担当は「距離で失う命中」だけ**（#71）: **石の威力は攻撃力の仕事、かわすのは相手の仕事**なので触らない。**天井は理性**（パワーは選ばない＝当たったとき何が起きるかを決める遺伝子が、当たるかどうかまで決めてはいけない）。**出生地の種は「その地域に落ちている石の数」**——**地面の種類ではなく石そのものから読む**（荒れ地はすでに渡り方を教えているので、1つの読みから2つのスキルを種付けしない＝38a）。**的の大きさを先に書いた**（段階44 の習慣）: 腕の長さの命中 0.90 対 実測 0.64＝**距離が奪う26ポイント**が上限。**測定: 狙ったものは動くが集団には届かない**（命中率 +0.02〜+0.03 \*\*\*、保有率 4〜8%・実効 0.08〜0.12＝**積は 0.3%**）。**ただし強い用量で `shRationality` +0.01 \*・`dRationality` +2.24 \* が出た＝スキルが自分の天井の遺伝子を買わせた初めての兆し**（38b は `shMemory` が5度動かなかった）。**理性はこの世界で一番買われていない遺伝子**なので、そこに掛けたスキルが弱いのは道理でもある。

- **石を投げる（段階46、`engine/throw.go`）** — **既定はオフ**（`Throwing`。`cmd/devview -terrain` は on）: **世界が始まって以来はじめての新しい傷つけ方**で、**行動語彙の10 番目**。**近接のスキル化ではない**（#64 が禁じたのはそれ、#71 が線を引いた）——**ダメージ・守り・かわしは既存の3遺伝子が近接と同じ式でやり、投げられた石は他の打撃と同じ一覧に入る**。**間合いは腕（15）より長く視界（130）より短い**（70。**見えない相手は狙えない**＝段階19 の約束）。**弾を消費し**（無ければ候補に挙がらない＝段階25 の線引き）、**石は消えず相手のそばに落ちる**（総量不変）。**外しても隙はできない**（段階24 は流用しない）。**命中は距離で落ち、その目減りだけが段階47 の担当**。**既定オフで始めた理由と、外れた予想**: 段階12a は「実在しない報復への恐れ（信念0.70 対 実際0.15）が世界を支えている」と測っており、**遠隔はその実際をさらに下げるはずだった**。**実測は逆で `trueRetal` は上がった**（+0.01 \*）——**石は逃げ道ではなく招待状**で、**投げた身体は唯一の石を失い、詰めてきた相手と近接で戦うことになる**（もう1つの読みは「投げる相手は元気な身体で、元気な身体は殴り返す」）。**当たったのは逃走のほう**（`escapeShare` −0.02 \*\*＝逃げ切れなくなる）。**個体数 −6.42 \***・出生 −23.02 \*・`rareTrough` −0.04 \*（弾の多い荒れ地の地図。**遊ぶ地図では −2.9 で誤差内**＝供給が薄いので発火しない＝段階45 の数え上げどおり）。**ダメージ3倍では明確に壊れる**（個体数 −11.90 \*\*、餓死率 +0.34 \*、`dPower` +3.99 \*）。**誰も石を貯めない**（`stoneHeld` ≈ 0＝拾ってすぐ投げる）。

- 戦闘の構え（`engine/stance.go`）: 戦闘系の行動は effort を「殴る・守る・かわす」の3チャネルに配分する。選べるのはプリセット3種（攻め寄り／守り寄り／逃げ寄り）だけ——自由配分にすると候補が立方体に増えるため。守りはダメージを減らすが同tickの打撃も減り、かわしは確率で丸ごと無効にする。**体力消費は Σ(チャネルの単価 × 使用率)** で、使っているチャネルは役に立たなくても払う。**食事中・休息中は無防備**（構えを持たない）。**相手の防御力・回避率は隠しパラメータ**（自分のものだけが効用式に入る）。

- 外すと隙ができる（`engine/stance.go` の `composure`、段階24）: **かわされた打撃は、外した側に隙を作る**（`OpeningTicks` = 3 tick のあいだ、その個体自身の守りとかわしが `OpeningGuard` = 0.4 倍）。**世界で唯一「外すこと」に値段をつけている規則**で、**`Perception` にも効用式にも載せない**（隙は3tick、判断は数十tickに1回なので、載せると一過性の状態を「この戦いのあいだ続くもの」として見積もることになる）。**予想を6つ書いて5つ外した**——`shEvasion` は動かず（+0.00）、`killRate` は上がり（+0.16 \*）、個体数は 6.75 \* 落ちた。**理由は「打撃のうちかわされるのは 5% しかない」こと＝規則の効き目の上限は発火頻度で決まる**（段階11 の `AffinityHunt` と同じ形の見落としを2回している）。**当たったのは向きが逆**——隙ができるのは**外した側**なので、群れで囲むことが罰される（`packSize` −0.03 \*）。**狙っていなかった良い変化はあった**: 少ないほうの種族の谷が浅くなり（`rareTrough` +0.06 \*）、仲間との戦闘比が下がる（`fightRatio` −0.10 \*）——攻撃一辺倒の身体（＝外敵）が一番この税を払うため。`OpeningTicks = 0` で完全に無効。

- 戦闘: 毎tickの継続ダメージ。殴る側のコスト < 殴られる側のコスト（攻撃側有利）。打撃は全員分をまとめてから同時に適用するので、スライス上の並び順が有利不利にならない。

- **種類ごとの死体と、種類ごとの動き方（2026-09-20、`EnemyKind.Meat` / `Climbs` / `Flies` / `FlyCost`）** — **4つとも既定はオフ＝1ビットも変わらない**: **`Meat` は死体の値打ちの倍率**（体の大きさに掛かる。未指定は1）で、**これだけが実装前の数え上げで「的がある」と分かっていたもの**——**肉は食事の 0.16（20000tick）〜0.30（200000tick）を占め、落ちた肉の 0.67〜0.80 は食べられている**（余っていない＝増やせば食べられる）。**`Climbs` は段差だけ**（ランプ無しで1段ずつ。コスト・溺死・速度・消耗は歩く者と同じ）、**`Flies` は上空**（段差を何段でも越え、溺れず、引きずられず、消耗せず、地面の代わりに `FlyCost` を払う）。
  - **「その地形の何を無視するのか」を4つに分けて書いた。** **地面がすることは4つ**（コスト＝段階20／溺死＝段階34／速度＝段階97／消耗＝段階99）**＋段差**で、**「水を無視する」という1つのフラグは黙って5つ全部を意味してしまう**。**`Water`（段階63）が束ねてよかったのは、それが本当に1つの事実だから**（川に住むものを川は取らない）。
  - **飛ぶことをただにしない。** **段階20 の「渡れない地形は作らない」の鏡**で、**`FlyCost` の未指定は0ではなく1**。**谷をただで越えられる飛行型を作ると、谷は地形であることをやめて背景になる。**
  - **移動能力のほうは、実装前の数え上げでは的が小さい。** **地形は今、居場所を面積比までしか動かしていない**——**plateau の地図で `onHigh` 0.33**（高台は面積の約28%）、**river で `onDear` 0.13 / `onWater` 0.13**（川は面積の約12.5%）。**身体は高いところにも水の上にも、面積なりに居る。** **だから「またげること」の値打ちは、地形が誰かを閉じ込めている地図でしか出ない**——**作ったのは、そういう地図を描けるようにするため。**
  - **地図が「どの国にどの獣がいるか」を言える**（2026-09-20、`Config.EnemyKindMap` ＋ `EnemyKind.Key`、Tiled の `enemy` プロパティ）。**植物の種類とまったく同じ形**——**1セル1文字＋凡例**、**地図は名前と場所だけを運び、数値は運ばない**（決定#133）、**地図が名付けて表に無い種類は行が増える**（ただし**外敵は `Share` が0だと1度も来ない**ので、**名前だけの行には `Share` 1 を入れる**——「その国の獣」と名付けたなら来なければ意味がない）。**`Share` が決めるのは「どの種類が来るか」、塗りが決めるのは「どこに」**で、**塗られていない種類は今までどおり `EnemySpread` と `Homing` で来る**。
  - **飛ぶことは取引にした**（2026-09-20、`engine/aloft.go`）。**`Flies` の身体は、地面に手を伸ばす行動（`ActEat` / `ActAttack` / `ActTake`）をしているとき以外は空にいる**。**空にいるあいだは殴る候補に出ず**（**呼びかけての共同攻撃も出ない**。**効用を下げるのではなく候補から消す**＝段階25 の「身体にできないこと」の門）、**殴っている最中に相手が上がれば打撃は当たらず「考え直せ」になる**。**石は届く**（段階46）——**地面の側の唯一の答えで、だからこれは無敵ではなく取引**。**降りることは別の決定ではない**——**食べる／殴るを選んだことがすでに降りること**なので、**閾値も新しい語彙も1つも増えていない**。**採らなかった形は「実際に `CombatRadius` の内側にいるときだけ降りている」**で、**そのほうが正確だが、近づく間じゅう安全で1tickだけ的という「形式だけの無敵」になる**うえ、**距離の計算が3箇所増える**。**飛び込むと決めたことが露出**。
  - **飛ぶ高さは種類ごと**（2026-09-20、`EnemyKind.FlyHeight`）。**目盛りは地図のタイルの `height`（1〜9、段階20 から読んでいるもの）そのもの**——**地図が「この国はどれだけ高いか」を、行が「この獣はどれだけ高く飛ぶか」を言う**（決定#133。**数値はどちらも相手の側に置かない**）。**上限（0 は上限なし）を超える地面には跳ね返され、そのときは歩く者と同じ道が使える**（ランプ・1段の段差）——**飛ぶことは余分な通り道であって、劣った通り道ではない**。**低く飛ぶ獣にとって高い台地は壁になり、高く飛ぶ獣にとってはならない**、という書き分けが地図の側の `height` だけでできる。

- **巣は点になり、半径は行の数字になった（2026-09-20、`Agent.HomeX/HomeY` / `EnemyKind.Roam` / `Config.NestInherited`）** — **既定の世界は変わらない**（`EnemyHomeCost` が0のままなら誰も家を読まない）: **段階64 は「世界に入ってきた地域の中心」から課金していた**が、**地域が務めていたのは半径のほう**（「10歩さまよった身体は家を離れていない」）。**点＋半径にして、半径を行の数字にした**（未指定は地域幅の0.5＝それまでと同じ）。**巣そのものは `EnemyKindMap` が塗ったセル**で、**Tiled のオブジェクト層に点を置く経路は作らなかった**——**セル単位で種類を置く手段がもうあるのに、2つ目の置き方を作る理由が無い**。
  - **実装前に数えて、段階64 の記録が再現しないことが分かった**: **`prowlGain`（湧きの偏りが居場所に残る割合）は 6%→45% ではなく 0.00 ± 0.02**（2度のベースラインのリセットを挟んでいる）。**湧きの偏りは居場所に1つも残っていない。**
