- **見失った方角（段階55a、`engine/lonely.go`）** — **既定はオフ**（`LonelyValue` = 0）: **好意が最大の相手を見失うと、その方角を1本だけ覚える**（**座標は持たない**＝#70 に踏み込まない。**方角は相手が見えているあいだに取る**ので、座標が書かれる瞬間がどこにも無い）。**薄れ、十分古くなれば捨てる**。**新しい行動は作らず、さまよう先の候補が1つ増えるだけ**（段階15b の「良い地域へ行く」と同じ形）。**着手条件を2つとも先に確かめた**——段階52 の `halfLife` は 38.8 → 59.0 だが**目標は 150**（上げ幅の3分の1は密度についてくる）、**的は「好意のある相手が視界にいない時間が 0.460」**（＝「規則が発火しない」型の失敗ではない）。**測定: 発火は十分すぎるほどした**（1実行に2880回見失い、42% が方角を持ち、**全決定の7%がその方角へ歩く**＝15b の 0.05 より多い）。**そして集団の指標はどの用量でも、どちらの向きでも下がった**（`halfLife` −6.7〜−14.3、`clumping` −0.05〜−0.25、餓死 +7〜+22）。**逆向きを指す対照は6倍悪い**（`clumping` −0.36 \*\*\* 対 −0.06 \*）＝**覚えていた方角は実在する情報で、でたらめよりずっとまし**。**それでも一番良くて「探しに行かない世界とほぼ同じ」**。**機序は「探しに行く身体は今いる集団を捨てる」**（探す相手は1人、捨てる集団は数人）＝**集団を保つために作った規則が集団を壊した**。**段階30b・31・35・49 の「知ることは起きるが行動は変わらない」とは別の失敗**——**今回は行動が変わったうえで世界が悪くなった**。**だから 55b（地域信念版）は作らない**（失敗しているのは粒度でも正確さでもなく「行くこと」そのものなので、粗くしても同じところで失敗する）

- **交配のときに配偶者が伝え合う（段階65、`MateLoreChance`）** — **既定はオフ**（0）: **出産の瞬間に、確率で1回だけ既存の `exchangeLore` を呼ぶ**（信念5つ・ヒント・スキル・地域の知識がまとめて動く）。**新しい交換式も配偶者専用の内容も作っていない**——**`exchangeLore` は段階12b からずっと関係を読まない**まま。**なぜ出産の瞬間か**: **ペアが手を組んでいるあいだの交換は実測でゼロ**（`stepPaired` は二人を歩かせるだけで `Decide()` も `ActObserve` も走らないので、**届く経路が存在しない**）で、**この世界では交配と出産が同じ瞬間**だから。**父からの伝承には何もしていない**——**父子が伝承の射程に居合わせにくいのは段階53a でガーディアンを母に固定した構造的な帰結**で、**増やす仕組みも塞ぐ変更も同じ線を壊す**。**測定（48シード）: 狙った量は動き、世界は動かない**——`mateGap`（出産の瞬間の親2人の隔たり。**交換の前に読む**ので**近い者どうしが番うようになったぶん**）2.37% → 2.18%（−0.19 \*\*）、`loreSpread` −0.12〜−0.18 \*、`teachTop` −0.01 \*、**個体数は1 SE で用量5倍の腕が一番小さい＝雑音**。**足しているのは交換全体の1%なので、世界が動かないことは失敗ではなく前提**。**そして `loreRate` は足したぶんより大きく上がる**（+8〜14 \*\*）＝**直接の効き目と、それが世界に与えた変化の二次的な効き目を同じ列で見てはいけない**

- 地域の豊かさの認識と伝承（`engine/regionlore.go`）: 個体は**自分が立った地面の豊かさを覚え**（15b）、**交換で伝える**（15c）。**自分が立った場所しか覚えられない**ので、行ったことのない場所は聞く以外に知りようがなく、それが伝承に価値を与える。**新しい感覚も新しい記憶の種類も作らない**（読むのは「見えた食料の数」、鮮度は既存の遅延減衰＋接触リセット）。**人の記憶の枠は1つも食わない**（場所は人ではない）が、**記憶遺伝子は country をどれだけよく保てるかを買う**。覚えたら**そこへ向かう選択肢が1つ増える**＝段階14 に欠けていた「選べる」。**これまでで一番強い凝集が出た**（`nearest` 140 → 100、`clumping` +0.19 \*\*\*）が、**それは15c（伝承）から来ている**——伝承を切ると凝集はまったく起きない。**知識の3分の2は人から聞いたもの**。**「知ること」と「選ぶこと」は別**（知るが行かない条件は個体数 −11.0 \*）。**`shMemory` は動かなかった**（地域12個では容量が制約にならない）。**伝えることは知識を広めるが一致はさせない**（意見のばらつきは伝承の有無で変わらない）。 **地形の行きにくさも同じ記録に入る（段階29、2026-09-06）**——**足元の移動コスト倍率を同じ訪問の平均として畳み込む1スカラー**（荒れ地・水・高さを別々の信念にしない。**誤読は足さない**＝足元は正確に感じられ、分からないのは「地域のどれだけが足元と同じか」）。**薄れない**（`RegionCostForgetPerTick = 0`。地面は留守中に動かない。ただし**同じ関数を通してある**ので、地形が動的になれば率を入れるだけ）。**候補に挙げる門は今までどおり食料の記憶の鮮度で、行きにくさは順位だけを変える**。**測定**: 荒れ地に立つ割合 0.48 → 0.42（−0.05 \*\*）で `clumping` +0.11 \*、代償は `killShare` +0.02 \*（個体数は誤差内）。**避けるようにはなるが半分にはならない**——信念が動かせるのは候補1つの順位だけで、**目の前の食料は地形と無関係に湧く**から。**重みを上げても頭打ち**（0/1/2/4 で 0.48/0.45/0.42/0.42、重み4は個体数 −11.5 \*）。**そして「自分で歩いた地面しか分からない」版が一番悪い**（個体数 −13.3 \*）——**未知の地域は「普通」と見なされるので、荒れていると知っている場所より未知のほうが良く見える＝知っていることが罰になる**。伝承がその歪みを消す。

- スキル（`engine/skill.go`、段階38a）— **既定はオフ**（`SkillBirthplace` = 0。`cmd/devview -terrain` は 0.5）: **ヒント枠の中身**として入る（1枠は言い伝えかスキルのどちらか、値段は同じ＝**新しい並行の仕組みを作らない**、#63）。**使って上手くならない**（練習のカウンタは無く、実効値の掛け算は `Agent.Ability` の1か所のまま）。**カテゴリごとに連続スカラー1本**（離散の等級表は `StrategyDepthUnlock` の轍）。**実効値は掛け算ではなく天井**——**min(名目, 適性遺伝子/100)**（既定の適性は速さ。`SkillAptitude` で差し替え可）。この形のおかげで**降格の規則が要らず**（子の実効値は自分の遺伝子が支える水準へ勝手に戻る）、**教えた側より教わった側がうまく使う**ことが起こる。**4種類目は毒耐性**（段階38b。段階17b の復活が前提。**毒のダメージと、その身体が警告に付ける値段の両方**を下げる＝**本命は後者**〈毒そのものは回復の2.1%、恐れの代価は個体数の17%〉。**`Self.PoisonResist` として知覚に載る**——「警告が何と言っているか」と「この身体にとってそれが何を意味するか」は別。**出生地が読むのはその地域に立っている株の平均の毒**＝**毒は地図に描かれていない**ので、「スキルごとに自分に対応する地域の性質を読む」形をここで一般化した）。**3種類目は泳ぎ**（段階38b。**水で死ぬ確率**を下げる＝**渡るコストではなく危険に効かせる**〈段階34 の「個体は川を渡らず川で暮らしている」に従う〉。天井は**体力**、出生地は**地域に占める水の割合**。**荒れ地の種からは水を外した**）。**2種類目は採取**（段階38b。**段階16 の飽きの割引への耐性**＝**競争ではなく効率**なので独占の余地が構造的に無い〈#64〉。適性の天井は**記憶**、出生地から読むのは**「地面が何を出すか」**で**痩せた地域ほど高い**＝**地形の無い世界でも成立する**）。**適性遺伝子はスキルごとの表**で、選び方の規則は2度とも「その行いが元から属している遺伝子」。**習得は3経路・マージは1つの比較演算**（新しい値 > 今の値なら置換）＝**出生地**（その地域の何を読むかはスキルごと。**誰も知らなくても始まる唯一の経路**）／**継承**（枠ごと）／**観察**（`observe` の交換に相乗り。**言い伝えは空き枠にしか入らないが、スキルは比べて上書きする**）。**天才は既存イベントを流用し、すでに持っているスキルだけを跳ね上げる**（無いカテゴリは発明しない＝**荒れ地の無い世界にはスキルが現れず、平坦な世界は1ビットも変わらない**）。**効き方は既存の掛け算1つ**（荒れ地の**超過分**の目減り＝どれだけ上手くても平地より安くならない）で、**知覚の `Self.Ground` もその身体の実効コストを返す**。**測定（48シード）: 拡散は起きた——名目 0.80／模倣なし 0.54／跳躍もなし 0.50（ばらつきゼロ＝出生地の値そのもの）＝跳躍が作り、模倣が配る**（跳躍は1実行に1.8回）。**保有率は模倣では動かない**（0.37＝**誰が持つかは出生地、どれだけ持つかは社会**）。**選別も出る**（`skillGap` +0.05 \*\*\*）。**しかし居場所は変わらない**（`onDear` +0.01 \*、超過コストを全部消して −0.00、`speedGap` +0.00、適性を頑丈さに変えてもニッチは出ない）。

- 協力の誘い（`ActInvite` と `engine/controller.go` の `scoreFight`、段階32）: **行動語彙が段階0 以来はじめて増えた**（`invite`＝「これを一緒に倒そう」。番号は末尾＝保存済みの世界の番号を動かさない）。**「宣言」は状態ではなく行動から読む**（`AgentView.DeclaredFor` ＝ 呼んでいる相手、またはすでに殴っている相手。`AttackingMe` / `CourtingMe` と同じ見える事実で、**持つと「呼んでから立ち去った個体が誘い続ける」嘘の状態になる**）。**同じ相手に宣言している者の力を、信頼のぶんだけ自分の側に足す**（`Affinity/AffinityTrust` × `AllyTrustWeight`。**好意は参加ボーナスではなく「土壇場で離脱しない確からしさ」**＝#56）——効くのは**勝率**と**相手が倒れるまでのtick数**の2か所で、**大きい獲物が「1人では倒しきれないが2人なら倒せる」**のはここ。**閾値も協力性遺伝子もパーティも作っていない**（信頼できる相手が視界に0人なら誘いは「攻撃＋無駄な時間」なので必ず負ける＝テストで固定）。**測定（48シード）: 群れ狩りは現れなかった**（`packSize` +0.02 \*、**語彙なしの対照でも同じ**、`jointHunts`・`hunts` は誤差内）——**段階11 の診断（足りないのは狙いを合わせる手段）はこれで否定され、保留#10 も閉じた**。**代わりに世界が良くなる**（個体数 +12.83 \*\*、世代 +0.23 \*、`dIntelligence` +5.04 \*、`killShare` 不動）。**出どころは人間どうしの袋叩きではない**（狩りにだけ味方を数える対照でも +13.08 \*\*）——**一番筋の通る読みは「同じ戦いを正しく安く値付けできるようになった」**（世界にはもともと同じ相手を殴る2人がいたのに、個体は「1人で殴る前提」で払いすぎていた）。**社会的な規則で予算比が動いた初めての例**でもある（`shSpeed` +0.01 \*\*、`shVitality` −0.01 \*＝**戦いを分け合えるなら頑丈さより脚**）。**誰も当てにしない世界は語彙ごと無い世界と1ビットも違わない**（期待0では1度も選ばれない）。
