- **飢えを速度として読む（段階93、`LookaheadReadsRate`）** — **既定は0**（`cmd/devview -rate`）: **`oneHorizon` のカウントダウンは締切**（`ticksLeft < PlanHorizon` の外では 0）**で、この世界の「余裕のある身体は何も欲しがらない」はその1行から出ている**。**速度の読みは同じカウントダウンをハザード**（`1 − exp(−PlanHorizon/ticksLeft)`）**として読み、重みで混ぜる**——**置き換えないのは、消えない裾が全員の危険を一様に持ち上げるから**（**一様な持ち上げは `LifeValue` を上げることと同じで、それは段階67 が単独で測った別の規則**）。**実装前に数えた的**: `pressure` = 0 が 0.107、**満ちて無傷の身体では 0.358**、**`keepValue` = 0 が 0.184（満ちた身体では 0.277）で、その100%が速度の読みで正になる**。**そして満腹の身体には締切そのものが無い**（残り時間の中央値は「減っていない」＝回復側）ので、**速度の読みが届くのは `keepValue` のように「もし足りなくなったら」を構成する経路だけ**。**測定（96シード）: 狙いは完全に当たり、主指標は逆に動いた**——**売買 −0.86 \*\*\***（**4分の1の用量でも −0.81 \*\*\* ＝用量の問題ではない**）、**1枚超の値段 −0.24 \*\*\***、**贈与 −320.90 \*\*\***、**個体数 −10.03 \*\***。**平坦な世界では個体数 −17.05 \*\*・餓死率 +0.84 \*\*\*で、一様な対照（`LifeValue` × 1.418）は −32.22 \*\*\***＝**形のぶんと水準のぶんは符号が割れる**（`killShare` −0.04 \*\*\* 対 +0.02 \*\*、`dIntelligence` +2.26 \* 対 −7.16 \*\*\*、逃走 −1.88 \*\* 対 +6.36 \*\*\*）。**気候の腕では狙いどおり寒さの取り分が下がる**（`chillShare` 0.48 → 0.45 \*\*）**が、外套は作られなくなり個体数 −18.84 \*\***。**`onCold` は動かない**（段階86 以来7度目）。**段階74 は速度の読みの下では損**（`rateblind` のほうが代価が3分の1＝**74 は遠い窓の飽和への対処だったが、速度の読みは近い窓も持ち上げるので「区別できるほう」が常に近い窓になる**）。**既定にすると20本のテストが落ちる**（2本は「壁が在ること」を固定していたもの＝狙いどおり。残りは**求愛・ペア・売買**＝段階73・74 が直した壊れ方の3度目）。**性能は `BenchmarkDecide` 20.3 → 36.9µs**（`math.Exp` が1決定に数百回。**既定では通らない**）

- **今の気分（段階54、`engine/mood.go`）** — **既定はオフ**（`MoodWeight` = 0。`cmd/devview -terrain` は 0.5）: **身体は「最近どうだったか」を2つの減衰するスカラー**（恐れ＝殴られて失った体力／満ち足り＝食事が実際に返したもの。どちらもその身体自身の上限に対する割合）**で持ち、それが効用式の中の1つの数の読み方を傾ける**。**傾けるのは事実ではなく好み**（`ShockRisk`＝段階12a が「世界に正解が無い」と切り分けた3つの1つ）なので、**怯えた身体は自分に確かめられることを何ひとつ間違えていない**。**選択は上書きしない**（2026-08-14 に一様ランダムが自殺的な攻撃を誘発して却下済み）。**相手ごとには持たない**（＝**恨みを持たない**という段階5 以来の線。誰に何をされたかは既存のリスク記憶が持っている）。**新しい検知は作らない**（打撃が通った行と、一口が実際に空腹と体力を動かした行に相乗り）。**読み出し時に減衰する帳簿**＝5つ目の状態量ではない。**測定: 強さと構造の両方がそろって初めて効く**——**弱い用量（好みを0.5% しか動かさない）では符号を逆にしても結果が同じ**で、**十分な用量で3つの腕が正しい順に分かれる**（**気分あり +7.77 \***／符号逆 −0.98／**同じ平均の傾きを定数として与えると −2.35 ± 6.05**＝**効いているのは平均の大胆さではなく、直前に何があったかに連動していること**。直接の対で +8.75 \*）。**片方だけでは足りない**（恐れだけ +4.98 ± 6.20、満ち足りだけ +3.10 ± 6.20）。**実装前に数えた半減期の効き方も当たった**（最後に殴られてからの窓ごとの割合 0.199/0.346/0.466/0.585/0.673 に対し天井 0.713＝**2/3 の時間立っている気分は定数**。600 に伸ばすと効き目が消える）。**外したのは2つの入力の大きさ**——**満ち足りは恐れの6倍**（食事は頻繁で大きく、打撃はまれで小さい）なので利得を分けた。**既定をオフにしたのは効き目が弱いから**（1.5〜2.0 SE、用量も手で置いたもの＝`ParentFeedShare` と同じ立場で、**上げる根拠は測定の側にある**）

- 意思決定の差し込み口: `Controller` interface（`Decide(*Perception) Action`）。`engine` はトリガー時にこれを呼ぶだけ。`World.SetController(id, c)` で1体だけ差し替えられる（将来の人間操作用）。`Perception` は他個体の真の能力を含まず、観測者自身の推定値だけを渡す。

- 行動の語彙: `ActRest` / `ActMove` / `ActEat` / `ActAttack` / `ActFlee` / `ActObserve` / `ActCourt` / **`ActInvite`（段階32）** / **`ActTake`（段階40）** / **`ActThrow`（段階46）** / **`ActGive`（段階48）** / **`ActOffer`（段階49）** / **`ActStore`（段階50）** / **`ActBuy`（段階51）** / **`ActCook`（段階52）** / **`ActWrite` / `ActRead`（段階69）** / **`ActDrop`（段階70）**。すべて effort（体力の注ぎ具合）を持つ。**語を足すと「言い伝えが何についてのものか」の幅（`numActionKinds`）も広がるので、既定でオフの語でも指紋テストの数値は動く**（段階32・40・46・49・52）。

- 再判断トリガー: 攻撃された／体力が一定量減った／目標を見失った・到達した／一定tick何も起きない／**視界に食料や配偶者が「入った」**。逃走用の閾値は存在しない。**「入った」であって「ある」ではない**（`SightingRetriggers` で旧挙動に戻せる）——2026-09-04 まで実装がレベルになっていて、食料の多い地域を歩く個体が毎tick 考え直していた。**直すと `Step` が2.4倍速くなり、同時に個体数がほぼ倍になった**（45 → 78 \*\*\*、餓死率4分の1）。理由は `ChoiceNoise` が候補のスコアに対して大きいこと——**毎tick 考え直す個体はそのたびにノイズを引き直し、僅差の候補の間で振動して何も遂行できない**。`CLAUDE.md` が最初から書いていた「毎tick 再計画する個体は計画を遂行できない」がまさにこれで、**2行のコードがトリガー方式の設計に穴を開けていた**。

- 視界（`engine/sight.go`）: **「自分が立っているセル＋周囲1セル」のブロック**（`SightGrid = false` で以前の半径130の円）。セルの大きさは**円と同じ面積になるよう較正**（76.8）——合わせないと「見える量」と「見える形」の変化が分離できない。**円との違いは粗さではなく、どこに立っているかに依存すること**: 近いのに見えない相手（セル境界のすぐ向こう）と遠いのに見える相手（対角セルの隅、最大177）が同時にいる。**「近い」が「見える」を意味しなくなった**のがこの段階の本体で、`neighbours`（円の物差し）が不動のまま `killRate` が −0.13 \* 下がる。**逃走成功率は動かない**（面積を合わせると逃げ切る距離の平均まで揃い、異方性は分散しか増やさない）。**視界のグリッドは空間インデックスとは別物**——インデックスは結果を変えてはいけない最適化なのでセル幅が `Config` に無く、視界は世界のルールなので `Config` にある。インデックスへの問い合わせは**半径ではなく矩形**（ブロックの中心に個体が立っていないので、半径で囲むと4倍近く舐める）。**視力は遺伝子ではない**。

- **先読みが食料について知っていること（段階78、`LookaheadHolds` / `LookaheadSpoils`）** — **既定はどちらもオフ**（既定の世界は1ビットも変わらない）: **78a は2つ目の窓に「手の中に何があるか」を見せる**（**level であって rate ではない**＝1食は空腹の1段の下げ。**割引は `LookaheadUpkeep` を流用**＝新しい数値を作らない）。**安全は構造から**——鎖は `p + (1−p)·next` で、**持っていても食べていなければ1窓目は動かない**（**餓死しかけた身体は手に食事があっても餓死しかけと読む**。テストで固定）。**78b は「必要になる瞬間までに腐っているものは取っておく値打ちがゼロ」**（`keepValue` に `keeps` を足し、**3か所に書かれていた同じ待ち時間を `shortfallIn` に括り出した**。`FoodView.Spoils` / `AgentView.OfferSpoils`＝**零は「腐らない」**＝世界の `SpoilAt` と同じ約束）。**測定（96シード × 2つの地図）: 78a は市場を倍にする**（遊ぶ地図＋お金で `sales` 1.76 → **3.35（+1.59 \*\*\*）**、断り −43.89 \*\*）**が、動かしたものは全部同じ機序で、それは段階67 の裏返し**——**手の中のものが「いずれ足りなくなる量」を埋めると仮定した身体は、手の中のものの `keepValue` を下げる**。**それは「取っておく値打ち」であると同時に `handWorth` を通じて「売るときに手放すものの値打ち」でもある**ので、**売り手が惜しまなくなり（売る）、預けなくなり（`storeIn` −153.88 \*\*）、拾わなくなる（`takeRate` −2.14 \*\*）**。**だから既定はオフ**——**「売買を増やすために後で要ることの値打ちを下げる」のは、P13 が解こうとしている問題そのものを悪くする取引**（平坦では両方入れると個体数 −9.41 \*・出生 −41.03 \*\*\*）。**78b は数えた的のとおり何も動かさない**（手の中の品のうち1窓で腐るのは 1.9%／0.5%、両方の地図で全指標が誤差内）。**実装前に数えた的は 78a が全身体の 0.75%／3.5%** で、**小さいのは構造的**（**食べ物を持っていて餓死を恐れている身体は、その食べ物を食べる**）。**そして入口に閂があった**: **`SelfView.HeldMeals` は段階71 から知覚に載っているのに全員ゼロ**（`heldMeals` が `CarryDiminishes` オフで即座に返す）＝**別の規則のために用意された欄は、その規則がオフのあいだ埋まらない**

- 効用比較（`AIController`）: 全候補を「生命の価値×生存確率の改善 ＋ 子孫の価値×成立確率 − 体力コスト − 時間コスト」で採点し、最良手を選ぶ。逃走・追撃・先制攻撃はすべてこの比較の結果として現れる。**食料レースの勝率は到達時間の比**（`RaceOnDistance` で旧・距離比に戻せる）——相手の速さは隠しパラメータなので世界の基準速度を仮定し、**両者が同じ effort で動くと仮定する**ので effort は約分され、残るのは脚の差だけ。**速さの予算比は動かなかった**（速さはすでに到達tick数を通じて効いていた）が、地形が入れば距離と時間は食い違うので先に直してある。

- 見た目からの学習（`engine/appearance.go`）: **2026-09-04 の申し送り決着**——体つきを読んだぶんの利得は 0（相関 0.08）。**`Appearance` が「攻撃力を見せないため」に攻撃力の予算上の競合（体力・速さ）から作られているのが原因**で、`LooksShowBulk`（総量を見せる）にすれば相関 0.50・利得 1.24 \*\*\* になるが、精度は上がらず個体数を払うので既定は変えない。以下は段階10 当時の記述: 初対面の相手に固定値を当てはめるのをやめた。**見えるのは体つき（`Appearance` ＝ 体力遺伝子と移動速度遺伝子の平均 × 年齢補正）だけ**で、攻撃力は入らない。各個体は強さの観測（戦闘・観戦）を「この体つきはこれくらい殴った」の1点として貯め、**最小二乗の直線を1本**当てて次の初対面に使う。**engine は写像を持たない**（同じ世界を見た2体でも違う線を引く）。**傾きは0へ引き戻す**（`AppearanceSlopePrior`。観測数が数十では素の傾きはノイズで、引かないほうがマシになる）。**記憶容量は消費しない**（覚える枠が無くて記録できなかった観察からも印象は残る）。利得は同じ実行の同じ遭遇で測る（`learnGain` +3.0、うち体つきを読んだぶんは +0.34）。**個体数は 22.8 → 14.8 に落ちるが、原因は学習ではなく水準**——`PriorStrength` を 50 から実際の平均（36）へ下げるだけで同じだけ落ちる（＝よそ者の過大評価が世界を支えていた）。

- **判断の揺れ幅という5本目の選好（段階95、`NoiseWeight` / `NoiseWeightSpread`）** — **既定は振幅1・広がり0**（`cmd/devview -wobble` / `-wobbleflat`）: **候補の採点の誤差にかかる倍率**。**段階95 まで、その誤差の大きさは `(100 − 頭の良さ)/100 × ChoiceNoise` の1本**で、**1つの遺伝子が「2つの手をどれだけ見分けられるか」と「自分の順位からどれだけ外れるか」の両方を決めていた**＝**「衝動的 vs 計算的」という進化軸が存在しなかった**。**置き場所は段階94 と同じ枠**（`lore`＝予算の外。**「もっと買える量」ではない**）で、**掛け算**——**スケールするのは元からある誤差なので、全部の手を見分けられる身体には動かすものがない**（テストで固定）。**設定は2つに分けてある**——**広がり（ばらつかせる）と水準（全員を一律に動かす＝対照）**。**この分け方が段階の全部**（段階54 の flat-bias 対照と同じ型で、**これが無ければ「ばらつきが効く」のか「単に騒がしいと効く」のかが区別できない**）。**実装前に数えた的はこの世界で最大級**（1決定の候補は平均 32.9、**最良と次点の差が自分の振幅より小さい決定が 85.2%**、**10分の1より小さいのが 48.2%**、**乱数を引き直すと勝者が変わるのが 69.8%**、1決定で捨てている効用は平均 3.37、一生の決定は約337）。**測定（平坦・96シード）: 水準は効き、ばらつきは効かない**——**一律 1.15 で個体数 −14.18 \*\*・出生 −40.66 \*\***、**一律 0.93 で +4.30・出生 +24.45 \***、**広がり 0.15／0.30 はどちらも誤差内**（+3.80 ± 6.75／+4.60 ± 6.75）。**決定的なのは水準を揃えた対照**——**伝承を切った世界では、選択が見つけた 0.93 を全員に配る腕が、ばらつく腕より良い**（**+14.35 \*\* 対 +10.96 \***。**どちらも 0.93 に着いているので差はばらつきそのもの**）＝**ばらつきは何も買っておらず、むしろ少し払っている**。**選択の意見は「下げろ」で bet-hedging は選ばれなかった**が、**それが見えるのは伝承を切ったときだけ**（既定の世界では平均 1.00 のまま −0.00。**引く乱数も2体の歩み寄りも平均を保つので動かせるのは選択だけなのに、伝承が広がりを 0.15 → 0.05 に潰して材料を残さない**＝段階94 と同じ比。**用量を倍にしても 0.06**）。**そして一番大きい発見は測り方についてのほう**——**`dIntelligence` と個体数が水準について逆符号で動く**（1.15 で **+4.27 \*\*／−14.18 \*\***、0.93 で **−2.22 \*／+4.30**）。**理由は構造的**で、**この世界で頭の良さがしている唯一の仕事はこの誤差を打ち消すこと**なので、**振幅を上げれば頭の良さの見返りが上がる**＝**`dIntelligence` は世界を騒がしくするだけで製造できる**。**`JudgementNoise` 側（理性が決める世界の読みの誤差）は作らない**——**同じ形の2本目に同じ答え以外が出る理由が無い**。**性能は `BenchmarkDecide` 22.7 → 22.8µs**（掛け算1つ）

- 効用式の中の仮定（`engine/lore.go`）: 効用式が使う5つの数値は**全ノード共通の定数ではなく個体ごとの値**。**2種類あり、どこから来られるかが違う**。**世界の事実**（殴り返される度合い・求愛が通る確率）は正解が世界にあるので走る平均で経験から学び、証拠の数には上限がある（上限が無いと老いた個体が世界の変化に気づけない）。**好み**（`RiskWeight` / `CompetitionWeight` / `ShockRisk`）は正解が無いので粒子的遺伝＋突然変異＋選択に任せ、世界の値の4倍でクリップする。**殴り返しの観測は「1回の戦い＝1票」**（engagement 開始5tick後に1度だけ。1打撃ごとに数えると長い戦いが答えを支配する）で、**学ぶのは殴った側と傍観者だけ**（殴られた側の選択は世界についての証拠ではない）。**信念の学習は既定でオフ**（`LearningRate = 0`）——動かないからではなく動くからで、真の殴り返し率 0.15 を知った世界は個体数が半分になる（増えるのは殺しではなく餓死）。**好みの側は既定オン**（`LoreInitSpread = 0.15`。0.25 は個体数を2割払うので較正して下げた）で、これだけで理性への選択圧が −6.95 → −0.83 に戻る。`World.Lore()` は集団の平均・広がりと**世界が実際にやっていること**（`TrueRetaliation` / `TrueAccept`）を返す読み取り専用の測定。

- **休むことは無防備であること**（`RestExposureWeight`）: `rest` の効用に「近くの好意の無い相手の推定の強さ × 近さ」を、休んでいる間ずっと入り続けるダメージとして乗せる（`PlanHorizon`/`ShockRisk` と同じ「分岐しない1本の軌道」の形）。`Decide` の先頭で近傍を1度走査し、被攻撃ダメージと露出を同時に作る。**重みは 0.05 と小さい**——`exposed` は `recoverable()` の中で `RegenRate`（0.09）から引かれるのに、隣人1人ぶんの脅威は 1.14/tick と12倍あるので、大きくすると勾配ではなく崖になる（視界に1人いれば休息の価値ゼロ → 消耗死 → 出産前のペアが壊れる）。
