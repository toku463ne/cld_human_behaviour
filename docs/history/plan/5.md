### 当初の計画（そのまま残す）


**目的**: **育児のあいだ母の実効速度を落とし、子と同じ場所にいる時間を増やすことで、母子の交換の機会を増やす**（#99）。**新しい「母子は近くにいるべき」という強制は作りません**——**母も子も、今までどおり全候補を効用比較します**。

**なぜ強制を足さずに済むと見るか**: **子はすでに `keepToGuardian` で圏外に出たときだけ引き戻され、それ以外は自分の効用比較で動きます**。**そして好意の高い相手を観察することはすでに正の効用項**（`LoreValue`、段階12b）。**母が動かなければ、母のそばに留まる値段が相対的に下がる**ので、**子は自分の判断で留まりを選ぶ回数が増えるはず**です。**これが正しければ、この段階の実装は掛け算1つとフラグ1つで済み、伝承の増加は既存の効用比較から創発します。**

### 形（先に線を引いておく）

- [ ] **`MaxSpeed` の掛け算には入れない。** `Agent.Ability` / `MaxSpeed` は**遺伝的素質 × 年齢補正 × 性別補正**という**世界の状態を知らない静的な鎖**で、**段階53 で `SexBias` を入れたときに「掛け算は1か所」と決めたのはこの鎖のこと**。**「今ガーディアンで子がそばにいる」は世界の状態**なので、ここに混ぜると**生涯を通じて意味の変わらない量**という性格が壊れます
- [ ] **形は段階54（気分）の流用**——**`Agent` 自身が持ち、`World` を経由せず `Agent` のメソッドから読める1つの値**（`Nursing`）。**状態量ではなく、毎tick書き直される事実の写し**（段階57 の `footing` と同じ立場）
- [ ] **判定は既存の距離判定の裏表**: `keepToGuardian` が**すでに** `stillReared(child)` と `dist2(child, guardian) <= RearingRadius²` を計算しているので、**その結果を母の側に1行書き込むだけ**。**新しい距離計算も新しい走査も増やさない**
- [ ] **毎tickの先頭で全部を偽に戻してから走らせる**（前のtickの値が残らないように）
- [ ] **速さを読む3か所を揃える**: `moveDir` の `speedAt(a.MaxSpeed(...))`、`evasion`（`engine/stance.go`。**`MaxSpeed` から回避率を作っている**）、`selfView` の `MaxSpeed` と `Evasion`。**揃えないと、実際には遅いのに回避率と知覚だけ元のままという食い違いが出ます**——**隠すべきは真の能力値であって、実効値が変わったこと自体ではない**
- [ ] **復帰（相談の4点目）に新しい規則は要らない**——**同じ判定の裏側**（圏外ならリセットされたまま偽）。**新しい距離定数を作らない**

**閾値についての線引き**（着手前に一度立ち止まって確認すること）: **`CLAUDE.md` が禁じている「ハードコードされた行動閾値」は、逃走・追撃・先制攻撃のような行動選択の閾値**です。**`Nursing` は母の行動選択を1つも変えず、身体の実効能力だけを変える**ので、**地形の段差（1段を超えたら進めない）と同じ「身体の物理的な事実」の側**だと見ています。**したがって圏内／圏外の連続的なフェードは要りません**が、**この解釈でよいかを着手時に確かめること**。
