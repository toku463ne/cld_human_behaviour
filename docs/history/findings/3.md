# 測定の記録 3（2026-09-23）——3つの国で村は保つか、何が難しさを決めるか

**問い**: **`typical` を4つの国に塗り直した**（左上＝民の始まる国、残り3つの4分の1がゴール）**あとで、それぞれの国に村を興したら保つのか。前日 `south` で測った「1人嫁いで 2/8」は国ごとに違うのか。**

**測り方は前日と同じ**（`docs/history/findings/2.md`）: 2000tick 走らせてから**国の中の1点**（`RegionCentre`）に村を興し（補充10年・100tickに1人・定員20）、5000tick 追う。**村の女を1人／3人「家系」に入れて**（結婚の代わり）、**その家系がその国から途切れずにいられるかを数える**。8シード。

**村はどの国でも必ず建って育つ**（1年後に2〜4人、5年で16〜18人＝定員近く、10年で14〜19人）。**世界の人口は 30〜37**（塗り直す前、左上の巣だけの世界は15人だった）。

**分かったのは「難しさは国の形が決める」ということ。** **前日、同じ仕掛けで `south`（離れた3つの塊）に村を建てたときは、1人嫁いで 2/8 しかもたなかった**。**今回、4分の1ずつの大きな国では 5〜7/8。** **「そこに住んでいる」は「その国の中に立っている」ことなので、国が小さく散らばっているほど、同じ家族が同じ国にい続けるのが難しい**——**値段でも土地の豊かさでもなく、塗りの形が難易度のつまみだった。**

**3人嫁げばどの国でも 8/8。** **「子を1人残して次の国へ」はまだ賭けで、3人置いていけば確実**、という手応えは前日と同じ。

**お金の回り方も測った**（20000tick、シード1）: **tick 4000 で60枚のうち32枚が誰かの手の中**（**一番持っている身体で15枚**）**だが、tick 12000 には60枚すべてが地面に戻っている**——**持ち主が死ねば落ちるので、お金は世界から消えない**。**プレーヤーが集めるときに競合するのは主に序盤。** **各国に落ちているのは12〜15枚**で、**3つの国の合計30枚は「世界の半分を集める」旅になる。**
