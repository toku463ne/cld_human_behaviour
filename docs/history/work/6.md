## 2026-09-09 段階46：石を投げる——世界を壊すはずの規則が、殴り返されにくくするどころか殴り返されやすくした

**`PLAN.md` の段階46。** **世界が始まって以来はじめての新しい傷つけ方**で、**この一連の段階で唯一、世界を壊しうる項目**。

**なぜ既定オフで始めたか。** 段階12a はこの世界の骨格を測っている——**個体は「殴り返される」を 0.70 と信じ、世界が実際にやるのは 0.15**、そして真実を教えると個体数が半分になる。**恐れが世界を支えている。** 遠隔は「殴り返されずに殴る」規則なので、**その実際をさらに下げるはずだった**。だから `TrueRetaliation` を個体数と並べて読む条件で作った（#71）。

**測定（48シード、弾の多い荒れ地の地図。基準は同じ地図で投げられない世界）。**

| | 既定の石 | 3倍痛い石 |
| --- | --- | --- |
| 投擲数 / 命中率 | 61 / 0.64 | 75 / 0.65 |
| **`trueRetal`** | **+0.01 \***（**上がった**） | **+0.01 \*\*** |
| `escapeShare`（逃げ切り） | **−0.02 \*\*** | −0.02 \*\* |
| 個体数 | −6.42 \* | −11.90 \*\* |
| `rareTrough`（希少種の谷） | −0.04 \* | −0.10 \*\* |

**1. 一番大きい予想が外れた。** **世界の本当の殴り返され率は下がるどころか上がった。** 一番筋の通る読みは**「石は逃げ道ではなく招待状」**——**投げた身体は唯一の石を失い、詰めてきた相手と近接で戦うことになる**（容量1なので2発目は無い）。もう1つの読みは**「投げる相手は元気な身体で、元気な身体は殴り返す」**——近接の打撃は弱った身体に落ちがちで、そちらは殴り返さない。**どちらの読みも同じことを言っている: 石は戦いを終わらせずに始める。**

**2. 当たったのは逃走のほう。** `escapeShare` −0.02 \*\*＝**逃げ切れなくなる**。段階3 以来の「劣勢側は逃げる」という逃げ道が、初めて細くなった。

**3. 値段は地図で決まる。** 弾の多い荒れ地の地図で個体数 −6.42 \*、**遊ぶ地図では −2.9（誤差内）**——**石が視界にある身体が19%しかいないので、規則がほとんど発火しない**。**段階45 で数えた供給がそのまま効き目の上限になっている**（先に数えておいた甲斐があった）。

**4. 誰も石を貯めない**（`stoneHeld` ≈ 0）。拾ってすぐ投げる——**手が1つしかないので、石を持つことは夕食を持たないこと**だから。

**5. 3倍痛くすると明確に壊れる**（個体数 −11.90 \*\*、餓死率 +0.34 \*、`dPower` +3.99 \*、`shAttack` +0.01 \*）。**遠隔が強い世界は攻撃力を買う世界**になる。

**作りで守った線。** 近接のスキル化ではない（ダメージも守りもかわしも既存の3遺伝子が同じ式で）。間合いは腕より長く視界より短い（見えない相手は狙えない＝段階19 の約束をAIにも）。弾を消費し、**石は消えず相手のそばに落ちる**（総量不変）。**外しても隙はできない**（段階24 の理由は間合いの外まで届かない）。**命中の距離による目減りだけを段階47 のスキルに残した。**

**そして石を拾う理由は、この段階が作った。** 段階45 では誰も石を拾わなかった——**使い道が無いものに効用式は値をつけない**。ここで「石は投げられることの分だけ価値がある」（`CarryValue` × 競合の強さ × 一発が仕留める割合）を足して、はじめて拾われるようになった。

**触った文書**: `NODE.md`（2-2・6節）、`PARAMETERS.md`、`README.md`、`CLAUDE.md`、`cmd/devview`（`t` で投げる。遊ぶ地図は on）、指紋テスト（**語彙が10 になったのでヒントの抽選が変わる**＝規則自体は既定オフで一度も発火しない）。


## 2026-09-09 段階47：投げる腕前——的を先に書き下し、上限どおりの結果になった

**`PLAN.md` の段階47。** 遠隔攻撃のうち**まだ誰も担当していない部分＝距離で失う命中**だけを担当するスキル（#71）。**石の威力は攻撃力の仕事、かわすのは相手の仕事**なので、どちらにも触らない。

**的の大きさを先に書いた**（段階44 で身についた習慣）。腕の長さでの命中は 0.90、世界で実際に測れる命中率は 0.64——**距離が奪っているのは26ポイント**で、**それがこのスキルに買えるものの全部**。

**測定（48シード、弾の多い荒れ地の地図。対照は同じ種を配って何も買わないスキル）。**

| | 既定の用量 | **強い用量**（石4倍・全員が学ぶ） |
| --- | --- | --- |
| 保有率 / 実効 | 0.03 / 0.08 | 0.08 / 0.12 |
| 命中率 | 0.64 → 0.66 | **0.62 → 0.65（+0.03 \*\*\*）** |
| 個体数 | ±0.0 | −3.98（誤差内） |
| `shRationality` | 0.07 → 0.06 | **+0.01 \***（`dRationality` +2.24 \*） |

**1. 上限どおりだった。** **保有率 0.08 × 実効 0.12 × 的 0.26 ＝ 0.25%**。段階38 が畳んだ式がそのまま当たり、**狙った量（命中率）は確かに動くのに、集団の数字は1つも動かない**。

**2. それでも、スキルが自分の天井の遺伝子を買わせた初めての兆しが出た**（`shRationality` +0.01 \*、`dRationality` +2.24 \*）。38b は記憶について5度測って `shMemory` を動かせなかったので、**弱いとはいえこれが最初**。

**3. そして掛ける先を選んだことの代償も見えた。** **理性はこの世界で一番買われていない遺伝子**（予算比 0.07。速さは 0.22）で、**天井が低いところに掛けたスキルは低いままになる**——頭の良さに掛け替えた腕では実効が 0.08 → 0.15 に上がる。**それでも理性のままにしたのは #71 の線**（当たったとき何が起きるかを決める遺伝子が、当たるかどうかまで決めてはいけない）で、**頭の良さは「手を選ぶ質」なので狙いの精度とは別の役**だから。

**4. 出生地の読みを石そのものから取った。** 荒れ地はすでに「渡り方」を教えているので、**同じ地面の種類から2つ目のスキルを種付けしない**（38a）。ただし**そのぶん種が薄い**——60個の石を12地域に撒くと平均5個で、**ほとんどの地域が平均以下の読みを返す**。保有率 4% はここから来ている。

**触った文書**: `NODE.md`、`PARAMETERS.md`、`README.md`、`CLAUDE.md`。**指紋テストは無変更で通る**（既定では投擲そのものがオフ）。


## 2026-09-09 段階48：門は開いた——物は動き、そして95%が他人へ動いた

**`PLAN.md` の段階48。P8 の門番**（#73）。通貨も倉庫も発信も配管であって、**誰かが何かを渡さないかぎり運ぶものが無い**。だから一番安い形だけを作って測った——**言葉1つ、取引なし、値段なし、帳簿なし**。

**渡す理由は「良い間柄になること」にした。** この世界にすでにある唯一の通貨がそれだからで、**共同で仕留めたときの好意（`AffinityHunt`）と同じ量を、同じ場所へ、双方向に**書く。**受け取るかどうかの規則は作らない**（受け取ることは損をしないので、手が空いていれば入るだけ）。**値付けも既存のもの**——`LoreValue`（誰かと一緒にいることの値）× **その贈り物が買う信頼の増分**。

**測定（48シード × 20000tick、同じ世界で贈り物が何も買わない腕と対）。**

| | 既定の世界（平坦） | 遊ぶ地図（食料が乏しい） |
| --- | --- | --- |
| 手渡しの回数 | **391**（1万のべ人-tickあたり 2.56） | 175 |
| **他人へ渡った割合** | **0.95** | 0.94 |
| 血縁へ / 配偶者へ | 0.05 / 0.00 | 0.06 / 0.00 |
| 個体数 | **+9.35 \*** | **−11.27 \*\*** |
| `killShare` / `fightRatio` | −0.01 \* / −0.04 \* | — |
| `dietVariety` | **+0.04 \*\*** | — |

**1. 門は開いた。** 物は動く。**通貨・倉庫・発信を作る前提は満たされた。**

**2. `PLAN.md` の予想は外れた——しかも一番面白い形で。** 予想は「血縁と配偶者の間では起きる／他人の間ではほとんど起きない」だったが、**実際は95%が他人へ**。**理由は値付けの帰結**: **信頼は飽和する**ので、**すでに親しい相手への贈り物は何も買わず、他人への贈り物が一番高い**。**「他人を信用する理由が無い」と予想していたのに、既存の好意の形がそのまま「他人にこそ渡す」を作っていた。**

**3. 贈り物は食事を多様にする**（`dietVariety` +0.04 \*\*）。**交換経済がやることそのもの**が、値段も市場も無いまま出てきた——**持っているものが違う2人の間で物が動けば、両方の食事が混ざる。**

**4. そして同じ規則が、豊かな世界では得で痩せた世界では致命的**（+9.35 \* 対 −11.27 \*\*）。**段階44（特産作物）とまったく同じ形**で、**食料を使う規則の符号は世界の余裕で決まる。**

**遊ぶ地図をひとつ直した。** 測っている途中で、**遊ぶ地図の個体数が9まで落ちていた**のを見つけた——**段階44 で入れた特産作物が、すでに餓死率の高いこの地図では収穫の3割を捨てさせていた**（28.8 → 11.6）。**平坦な世界では +10 だった同じ規則**。`cmd/devview -terrain` の用量を下げた（割合 0.2 → 0.08、成功率 0.25 → 0.5）ところ 24.8 に戻り、**特産作物は残しつつ遊べる世界になった**。

**触った文書**: `NODE.md`（2-2・6節）、`PARAMETERS.md`、`README.md`、`CLAUDE.md`、`cmd/devview`、指紋テスト（**11 番目の語彙が入り、しかも今度は実際に使われる**）。


## 2026-09-10 段階49：発信——語は使われ、聞かれ、そして「聞こえない対照」が同じだけ得をした

**`PLAN.md` の段階49。** 段階48 で門は開いた（物は動き、95%が他人へ動く）が、**そこに何かがあることを誰も言えなかった**——手の中の食料は持ち主にしか見えない（段階40）ので、余剰を持つ身体と欲しい身体は、互いに歩いてぶつかることでしか出会えない。**その「言う」を1語で作った。**

**実装前に的を数えた**（段階40・45 と同じ習慣）。

| 数えたもの | 平坦な世界 | 遊ぶ地図 |
| --- | --- | --- |
| 何かを持っている身体 | 0.27 | 0.28 |
| **そのうち空腹でない身体（＝余剰）** | **0.85** | 0.79 |
| **持っている身体が、空腹で手の空いた相手をすでに見ている割合** | **0.52**（平均距離 64） | 0.58（58.7） |
| **買う側の的**（空腹の瞬間のうち、食料が視界に無く、持っている誰かが視界にいる割合） | **0.029** | 0.023 |

**余剰は実在する。しかし売り手の半分はすでに買い手を見えており、買い手側の的は3%しかない。** 加えて試走で分かったのは、**売り物が視界にある決定のうち、地面の食料が1つも見えていないのは3%だけ**——**発信が明かすものは、たいてい地面に落ちていて見えている食料**。

**作った形**（`engine/offer.go`、`ActOffer`＝12 番目の語彙）。

- **記憶ではなく見える事実**（#74）。掲げているあいだ中身が全員の知覚に載り、**行動から読み、どこにも保存しない**（段階32 の `DeclaredFor` と同じ）。**目撃者スキャンは使わない**——あれは一瞬の出来事のためのもので、**売っている身体はずっと視界にいる**
- **対価は時間だけ**（`OfferTicks`＝`CallTicks` と同じ形）。**範囲は視界内だけ**。**閾値なし**
- **値付けは既存のものだけ**: 発信の値打ちは**その手渡しが買う信頼**（`addGive` と同じ）で、**違うのは代金と確からしさ**——歩いて渡すのは体力を払って確実、叫ぶのは時間だけを払い、**「来る側が鳴き終わる前に着けるか」**で割り引く（**相手の脚は隠しパラメータなので世界の標準速度を仮定**＝食料レースと同じ約束）
- **買う側に新しい語彙は作らない**——掲げている相手へ歩くのは、段階15b の「良い地域へ行く」と同じ `move` の1候補
- **売っているあいだも腐る**（#77。止めれば**売る気の無い身体が冷蔵庫として店を出す**）

**最初の版は買う側の値付けが5倍甘かった。** 実測すると**売り物へ歩いた5回に1回しか実際に渡されない**（0.206）のに、効用式は「鳴き終わる前に着けるか」だけで割り引いていた＝ほぼ1。**足したのは新しい定数ではなく、世界がすでに持っている競走**——**広告された品は競合品**なので、地面の食料とまったく同じ形で「他の誰かが先に着く」を割り引く（`OfferRivalDist`）。**これで聞こえる腕の損（対で −9.42 \*）が消えた**（−2.50 ± 6.55）。**段階40 が「拾う理由が粗すぎて個体数を4.5削っていた」のとまったく同じ形**。

**測定（48シード × 20000tick、3腕）。`WaresSeen = false` が肝で、これは「叫びはするが誰にも聞こえない」対照**——鳴き声は同じだけ選ばれ、同じだけ時間を払い、**情報だけが消える**（段階34 の `DrownKnown`、段階39 の「治ると知らせない肉」と同じ形）。

| | 語彙なし | **発信（聞こえる）** | **発信（聞こえない）** |
| --- | --- | --- | --- |
| 個体数（平坦） | 75.65 | +5.33 ± 6.54 | **+7.83 ± 6.59 \*** |
| 餓死（平坦） | 48.35 | −3.06 \* | **−4.42 \*** |
| `killShare`（平坦） | 0.81 | +0.02 \* | +0.02 \* |
| 個体数（遊ぶ地図） | 17.83 | +1.10 ± 4.11 | +4.08 ± 4.74 |
| `cryShare` / `offerHeard` / `offerDraw` | 0 | 0.01 / **0.03〜0.04** / 0.00台 | 0.01 / **0.00** / 0.00 |
| `giftsCried`（発信のあとの手渡し） | 0 | **0.05〜0.06** | 0.05〜0.06 |

**1. 規則は絶えず発火し、そして世界の数字は動かない。** 決定の0.5〜1%が発信、3〜4%が「誰かの売り物が視界にある」状態で下され、手渡しの5〜6%が発信のあとに起きる。**それでも個体数も死因も誤差の中**。

**2. 決め手は「聞こえない対照」だった。** 平坦な世界で餓死が減るのは**聞こえる腕でも聞こえない腕でも同じ**（−3.06 対 −4.42）。**つまり餓死を減らしているのは「誰かが聞いたこと」ではなく「立ち止まっていること」**——**この規則が世界に足した本当の新しさは、腹の減った身体が使える「待つ」という手だった**（`rest` は満腹でないと何も返さないので、空腹の身体にとって「安く時間を潰す」選択肢はこれまで無かった）。**遊ぶ地図で一番良かったのが90tick の長い鳴き声（+7.71 \*）**なのも同じ理由で、**長く立ち止まるほど得**。

**3. 「知ることは起きるが行動は変わらない」の4度目**（段階30b・31・35 に続く）。ただし今回は**一段深い**——**知ることは起き、行動も変わり**（歩く決定が実際に生まれ、手渡しが実際にそれに続く）、**それでも集団の数字は動かない**。**理由は的の大きさで、実装前に数えたとおり**: 買う側の的は3%、しかもそのうち97%は地面の食料も見えている。

**4. 既定はオフ**（`OfferTicks = 0`）。**動かないからではなく、情報が何も買わないから**——**同じ利得が「誰にも聞こえない鳴き声」で得られるなら、それは発信の値打ちではない**。`cmd/devview -terrain` では on（**遊ぶ側の語彙であり、見て分かるもの**＝段階46 の `Throwing` と同じ扱い）。

**5. 段階50・51 への申し送り。** **配管を測るときは「同じ時間を使い、情報だけが無い」対照を必ず対で回すこと**——この段階では、それが無ければ「発信は餓死を10%減らす」と書いていた。

**指紋テストは既定オフでも動いた。** 語を1つ足すと**言い伝えが何についてのものか**の幅（`numActionKinds`）が広がり、出生のたびの抽選が最初のtickからずれるため（段階32・40・46 と同じ）。**幅を元に戻せば `OfferTicks = 0` の世界は1ビットも違わない**ことを確認したうえで数値を更新した。

**もう1つ、乱数列がずれて表に出たものがある**（段階40 のときと同じ）。**手に魚を持ったまま陸で死ぬと、魚が乾いた地面に落ちていた**——「魚は水の中にしかいない」というテストがそこで落ちた。

**最初これをバグとして直した（魚を水へ戻した）が、それは間違いだった。** **陸に落ちているのが正しい**——世界が魚を**置く**のは水の中だけだが、**釣り上げられた魚はその身体のもの**で、持ち主が死ねば持ち物はその場に落ちる。抜け道だったのは場所ではなく**時計のほうで、釣り上げた魚が永遠に鮮度を保っていた**。

**直した形**: **釣り上げた瞬間に死肉の時計が始まる**（`SpoilAt`。**専用の数値は作らず `MeatSpoilTicks` を共有する**——死んだ魚と死体は名前が違うだけの同じもので、2つ目の数値は「どちらが効いたか」を測る理由の無い測定を増やすだけ）。**手の中でも腐り**（#77）、**岸に落ちていても腐る**。**世界が水に置いた魚には時計が無い**（生きているので腐らない）。**テストのほうを直した**——**押さえるべき不変条件は「世界は魚を水にしか生やさない」で、「魚は水にしか存在しない」ではなかった**（時計の有無でその2つは区別できる）。

**大きさは実測で、釣り上げられた魚の3%**（`fishSpoilShare`）。**段階42・43 の記録はこの規則が無い世界のもの**なので、`LandedFishKeeps = true` で戻せるようにし、**同じバイナリの中で対にして測った**（遊ぶ地図＋魚、48シード）: **個体数 −2.75 ± 4.42**、`gen` −0.58 \*、`rareTrough` −0.08 \*、餓死・溺死・`onWater` はどれも誤差内。**世界はほとんど気づかない。**

**ただし副作用が1つあり、向きが面白い**——**腐る世界のほうが川に魚が多い**（`fishItems` +2.18 \*\*、`fishShare` +0.01 \*\*）。**魚と植物は1つの枠を分け合う**（段階42）ので、**手の中で永遠に持たれている魚は枠を占めたまま川から消えている**。腐ればその枠が空き、世界がまた1匹生やす。**「食べ物を世界から減らす規則」が、食べられる魚を増やした。**

## 2026-09-11 段階54：気分——強さと構造の両方がそろって初めて効き、片方だけでは何も起きない

**段階12a の一般化。** 効用式は「殴り返される確率は0.7」と思い込んでいて、世界の実際は 0.15 で、**真実を教えると個体数が半分になった**——**世界を支えていたのは実在しない報復への恐れ**だった。**では、直前に何があったかに連動する偏りを意図的に入れたら、同じように世界を支えるのか。**

## 2026-09-11 段階53：性差の振り分け——役割どおりの配分が、役割を逆にした配分より悪い

**53a・53b で役割を作ったうえで、そこから逆算した配分を入れた**（#85）: 母に理性・防御力・記憶容量、父にパワー・速さ・頭の良さ、最大体力・回避率・魅力は中立。**掛け算は `Agent.Ability` の1か所**（年齢補正の隣）、**`Genome` と継承には一切触らない**ので両性は同じ遺伝子プールから出てくる（#4 を壊さない）。

### 測定（48シード × 20000tick、基準は同じ役割で配分なしの世界）

| 腕 | 個体数 | `shMemory` | 母の寿命 | 父の寿命 |
| --- | --- | --- | --- | --- |
| 配分 0.15 | **−15.96 \*\*** | −0.00 | −212.79 \* | +190.12 |
| 配分 0.30 | **−31.60 \*\*\*** | **+0.01 \*** | −383.04 \* | +1137.91 \*\* |
| **配分 0.15・性を入れ替え** | **−7.94 \*** | **−0.01 \*** | +282.48 \* | −433.22 \*\* |

**予想は2つ当たって1つ外れた。**

- **当たり**: 個体数は下がり、**下がり方は補正の大きさにほぼ比例する**（0.15 で −16、0.30 で −32）
- **当たり**: **集団全体の予算比の動きは、性別ごとの差よりずっと小さい**（どの遺伝子も 0.01 以内）。**性染色体が無いので、片方の性にだけ有利な遺伝子は次の世代で混ぜられる**（#4）——**性別ごとの差だけを見て「選択圧が動いた」と書かなくて正解だった**
- **外れ、そしてこれがこの段階の発見**: **役割どおりの配分（−15.96 \*\*）は、役割を逆にした配分（−7.94 \*）より悪い**

### なぜ役割どおりのほうが悪いのか

**この世界が金を払っている遺伝子と、役割が要求する遺伝子が別だから。** 予算比の実測は **速さ 0.22・頭の良さ 0.11** に対し、**防御力 0.06・理性 0.06・記憶 0.06**。**役割から逆算した配分は、動けない母に「この世界が一番払わない3本」を持たせ、「一番払う2本」を取り上げる**。**だから母の寿命が縮み**（−212.79 \*／強い用量で −383.04 \*）、**入れ替えた腕では逆に伸びる**（+282.48 \*）。

**「役割から逆算する」という方針（#85）は筋が通っているが、筋が通っていることと世界が報いることは別だった。**

### それでも記憶は6度目に動いた

**`shMemory` は段階9・12・15b・38b・52 と5度測って一度も動かなかった量**で、**強い用量の役割どおりの腕で初めて +0.01 \***、**性を入れ替えた腕では −0.01 \*** と**符号が役割についてくる**。**測っているのは継承された遺伝子**（`Gene()`＝発現ではない）なので、**これは掛け算が透けて見えているのではなく本物の選択**。

**ただし買った値段は個体数の3分の1。** **「記憶に値段をつけることはできるが、そのためには世界を貧しくするしかない」**というのが、段階9 の宿題に対する6度目の答え。

**そして 53a・53b の役割だけ（配分なし）でも `shMemory` は +0.01 \* 動いていた**（同日の前の項）——**動かしているのは遺伝子の振り分けよりも「動けず、周りに生死を左右される個体が世界にいること」そのもの**かもしれない。

### 拾ったおまけ

**どの配分の腕でも `clumping` が +0.12〜0.16 \*\*\*、`halfLife` が +10〜11 \* 上がる**（あるべき状態D の指標）。**性差そのものが集団を持続させる方向に働いている**が、**個体数と引き換え**。

**既定は全部ゼロのまま**（手で入れた差は発見ではない、という #85 の線と、個体数の代価）。

### そして集団の指標は、どの用量でも、どちらの向きでも下がった

| 腕 | 個体数 | `clumping` | `halfLife` | `together` | 餓死 |
| --- | --- | --- | --- | --- | --- |

| 値打ち 20 | +2.12 ± 6.17 | −0.06 \* | **−6.74 \*** | −0.01 \* | +6.96 \*\* |
| 値打ち 60 | +1.88 ± 5.04 | −0.25 \*\*\* | **−14.33 \*\*\*** | −0.04 \*\*\* | +21.73 \*\*\* |

| **逆向きの対照**（値打ち 20） | +2.62 ± 5.57 | **−0.36 \*\*\*** | **−12.82 \*\*\*** | −0.04 \*\*\* | +6.54 \* |

**逆向きの対照がはっきり悪い**（`clumping` −0.36 対 −0.06、`halfLife` −12.8 対 −6.7、`gapRel` +0.11 \*\*\* ＝集団がばらける）。**つまり「覚えていた方角であること」は実在する情報で、でたらめな方角より6倍ましである。** **しかし一番良くても「探しに行かない世界とほぼ同じ」までしか届かない。**

**機序ははっきりしている**——**探しに行く身体は、今いる集団を捨てる。** 探している相手は1人、捨てる集団は数人。**だから集団の持続（`halfLife`）が下がる。** **餓死も増える**（値打ち20 で +6.96 \*\*、60 で +21.73 \*\*\*）＝**思い出を追って歩くぶん、食べていない**。

### だから 55b は作らない

**55b（地域ごとの信念に「気心の知れた相手の多い地域」を足す）は、同じ考えを粗い粒度でやり直すもの**だが、**ここで失敗しているのは粒度でも正確さでもない**（逆向きの対照が、情報は正確で有用だと示している）。**失敗しているのは「行くこと」そのもの。** **粒度を粗くしても、身体が集団を離れて歩くことは変わらない。** **55b・55c はどちらも保留のまま置く。**

## 2026-09-12 段階57：地面を持ち歩けなくしても居着かない——約分されて消えるから

**6度目の不発。ただし、これまでの5度とは失敗の仕方が違う。**

**実装前の予想では、動かなかったときの容疑者は「移動先の地面が知覚に載らないので、効用式が『離れると失う』を値付けできないこと」だった**（段階20 の「この先も足元と同じ地面」）。**測ってみると、容疑者はもっと手前にいた。**

| --- | --- |

**地域は 200 × 200 で、殴り合う2体は必ず同じ地域にいる。** **効用比較も戦闘の解決も読むのは相対的な強さ**なので、**両側に同じ倍率が掛かれば消える**。**±30% の倍率を全員の全遺伝子に掛けても、その場の勝ち負けは1ミリも動かない。**

**つまりこの段階が見つけたのは、「地面に置くと消え、身体に置くと効く」という非対称**である。居着きの役には立たないが、**規則をどこに置くかが効き目を決める**という点では段階31（無料の情報が記憶の枠で頭打ちになる）と同じ形の発見になった。

## 2026-09-12 段階57c：約分は止まった。それでも並び替えは起きない——一生のうちに平均されるから

**57a の診断は正しかったが、診断を直しても結果は同じだった。**

**57a が動かなかった理由は約分**（地域の全員に同じ倍率が掛かるので、勝ち負けを決める比較から消える）。**57c はそれをやめた**——**地域ごとに「どの遺伝子を贔屓するか」を変え、9本の平均を1に正規化する**（**良い地域／悪い地域は作らない**＝良し悪しは段階15a の食料がすでに担当している）。**隣どうしで建て方が違えば違う倍率を受ける**ので、**約分は構造的に起きない**（テストで固定）。

### 的は実在した

**`suitCeiling`＝その身体にとって一番合う地域が、平均的な地域よりどれだけ良いか**（48シード）:

| 用量 | `suitCeiling`（％） | `suitGain`（％） | 取れた割合 |
| --- | --- | --- | --- |

| ±0.6 | **15.51 \*\*\*** | +0.32 ± 0.20 \* | **2%** |

**世界には 7.6%〜15.5% の並び替えの余地があり、集団が取ったのはその2%。**

### そして取った2%も、立っている場所とは関係がなかった

**決め手は対照**（`favourcarried`＝同じ好みを出生地から引いて一生持ち歩く。**その身体の倍率は、今どこに立っているかと無関係**）:

| 腕 | `suitGain`（％） |
| --- | --- |
| 地面に置く（±0.6） | +0.32 ± 0.20 \* |
| **持ち歩く（±0.6）** | **+0.30 ± 0.21 \*** |

**同じ大きさ。** **持ち歩く腕では「合う地面に立つ」ということが起こりえない**ので、**この +0.3 は立つことではなく生まれ落ちた運**——**自分に合う地域で生まれた身体が少し多く生き残っている**ぶんである。**したがって、地面に置いた腕で観測された並び替えのうち、「どこに立ったか」に由来するぶんはゼロ。**

### 理由は、一生のうちに平均されること

**57a で数えた数字がそのまま答えになる**——**1つの身体は一生に 12地域のうち 5.9 に立つ**（`regionsSeen`。`oneRegion` は 0.07）。**place に縛られた倍率は、半分の地図を歩く一生のあいだに地図の平均へ均される。** **選択が見るのは一生の成績なので、平均されたものからは並び替えが出ない。**

### 予想の答え合わせ（5つ書いて3つ外した）

- **「`suitGain` が正になり用量に応じる」＝半分外れ**。**正にはなるが、対照と同じ大きさ**なので、**この段階が足したぶんはゼロ**
- **「対照では `suitGain` ≈ 0」＝外れ**。**そして外れ方が一番の収穫**——**対照が測っていたのは出生地の運で、それは実在した**
- **「居着きの指標は動かない」＝当たり**（`regionsSeen` −0.10 \*、`oneRegion` ±0.00）

### 段階57 全体の結論

**2つの形で試して、2つの別の壁に当たった。**

1. **地面に同じ倍率を置く（57a）→ 約分される**（殴れる距離にいる組の100%が同じ地域）

## 2026-09-12 段階59：外敵の種類は表の1行——そして種類は種ではない

**「種類を増やしやすくする」ことが要件だった**ので、そこを設計の中心に置いた:

- **行を足す以外に何も要らない。** **どの規則も行数を数えず、表を読む**。**3行の世界が1行のコードも足さずに動くことをテストで固定した**（`TestAThirdKindNeedsNothingButARow`）
- **空欄は世界の既定に落ちる**（予算を書かない行は `EnemyBudgetMean` を使う）ので、**「湧く場所だけ違う種類」が1行で書ける**
- **割合は正規化する**ので、合計を1にする必要はない
- **意思決定エンジンには種類の分岐を1つも作らない。** 「この種類はどうするか」を訊きたくなったら、**答えは行の上の数字**（何を食べるか・どこまで離れるか・どれだけ湧くか）にする＝**新しい種類が新しい case にならない**
- **`Homing` を「種類ごとの地図」にしなかった**のは、**危険な土地は1つ**だから——2つの種類が別々の地図を持てば、危険な土地が2つになる

### 種類は種ではない（実装して初めて決まったこと）

**最初の実装は「子は親の種類を継ぐ」と書いていた**が、**テストが「0 の親から 1 の子が生まれた」で落ちた**——**求愛は種の中でするが、種類は見ていない**。**つまり種類はすでに交配する。**

**決めたのは「予算と同じコイン」**（#2＝どちらの親から継ぐかは50%）。**種類が違うときだけコインを投げる**ので、**1種類の世界は乱数を1つも引かない**。

### 測定（48シード × 20000tick）

**読むのは baseline ではなく `kindssame`**（**同じ中身を2行に分けただけの対照**）。**baseline と比べると段階58 の `EnemySpread` のぶんが混ざる**（実際 `kindssame` の `halfLife` −5.16 \* は 58 単独の −5.20 \* とほぼ同じ）——**対照を用意した意味はここにあった。**

| 指標 | kinds（軽×3・重×1） | kindsheavy（軽×1・重×1） |
| --- | --- | --- |
| `kindGap`（重い行と軽い行の予算比） | **+0.47 \*\*\***（1.57） | **+0.48 \*\*\***（1.58） |
| `kindMix`（湧きの内訳と表の差） | −0.02 \*\*（0.05） | −0.00（0.07） |
| `kindHomed` | +0.01 ± 0.02 | −0.01 ± 0.01 |
| 個体数 | +1.48 ± 5.41 | −3.69 ± 4.46 |
| `killRate` | **+0.20 \*\*** | +0.02 |
| `rareShare`（外敵の割合） | **−0.03 \*\*** | −0.00 |
| `dPower` | **+3.69 \*** | +1.41 |
| `dIntelligence` | −1.80 ± 2.80 | **−3.98 \*\*** |
| `hunts` | −7.46 ± 8.13 | **+8.15 \*** |
| `halfLife` | −1.96 ± 3.19 | **+6.45 \*** |
| `packSize` | −0.06 \* | −0.02 |

**表は設計どおり動く**（`kindGap` 1.57 対 対照 1.10＝**対照の 1.10 は「同じ行を2つに分けたときの標本誤差の底」**）。**`kindHomed` は動かない**——**段階58 の結論（湧きの偏りは一生のうちに散る）が、種類ごとに分けても同じ**。

**そして混ぜ方が世界の選択を変える**: **重いのが4分の1のとき、世界は殺しが増えパワーが買われる**（`killRate` +0.20 \*\*、`dPower` +3.69 \*）。**重いのが半分のとき、狩りが増え人間は集まって長く一緒にいる**（`hunts` +8.15 \*、`halfLife` +6.45 \*、`clumping` +0.07 \*）**が、頭の良さへの選択圧を払う**（`dIntelligence` −3.98 \*\*）。

### 予想の答え合わせ（5つ書いて2つ外し、1つは半分）

- **「`kindMix` はほぼ0」＝外れ**。**0.05〜0.07 が底**で、**理由は標本**——**1実行の到着は48体しかない**ので、`|p̂ − p|` の期待値は 1/√48 ≈ 0.07。**この指標の底は到着数で決まる**（表の再現性ではなく）
- **「`kindGap` は 1.5 前後」＝当たり**（1.57／1.58）
- **「対照は baseline と差が出ない」＝半分外れ**。**差は出たが、それは段階58 のぶん**だった＝**対照は正しく働き、読み方のほうを間違えかけた**
- **「`kinds` の個体数は baseline とほぼ同じ」＝当たり**（+1.48 ± 5.41）
- **「`kindsheavy` は個体数が下がり `packSize` は動かない」＝半分当たり**（個体数 −3.69 は誤差内、`packSize` −0.02 ＝**段階11 の「大きい獲物は群れ狩りを呼ばない」がここでも成り立つ**。**ただし `hunts` は +8.15 \* と動いた**＝**狩りの回数は増えるが、1回あたりの人数は増えない**）

### 既定は空の表（＝1種類）

**測定用には2種類で足りる**が、**増やすときに1行で済むこと**がこの段階の成果物。**既定の世界は1ビットも変わらない**（指紋テスト）。
