**ユーザの提案から**: 「先読みでセルを読むとき、現状が平常時より体力回復が速く、かつ現セルと次のセルを比べて結果が変わらなければ、次のセルを選びやすくする。もしくはどちらを選ぶかは確率にする。」

**先に、同点を今は誰が勝っているのかを調べた。** **`pick` は `score > bestScore` で選ぶので、同点は候補の並び順で決まる**。**その順は `addWarmth` → `addRest` → `addExplore`**——**つまり同点なら「留まる」が勝つ。** **誰も選んでいないバイアスがそこにあった。**

**そして「同点」がどれだけあるかを測る計器を足した**（`Stats.ChoiceGap` / `ChoiceCoin`。**読むだけで、タイの崩し方は1つも変えていない**）: **勝った手と2位の差**と、**その差が自分の評価ノイズより小さかった決定の割合**。

| | baseline | cold | coldhard |
|---|---:|---:|---:|
| `choiceGap`（勝った差） | 6.85 | 6.85 | 6.65 |
| **`choiceCoin`（ノイズより小さい差で勝った割合）** | **0.72** | 0.70 | **0.64** |
| `intelligence` | 54.1 | 56.5 | 63.6 |

**(1) 既定で 0.72。** **決定の7割は、身体が上位2手を見分けられていない。** **実質コイン投げ。** **だからユーザの案の後半——「どちらを選ぶかは確率にする」——は、すでにそうなっている。**

**(2) しかし寒い世界では、タイはむしろ少ない**（0.72 → 0.64、−0.08 \*\*\*）。**理由は知能**——**厳しい寒さは知能を強く選抜し**（54.1 → 63.6、+9.5 \*\*）、**知能が高いほど評価ノイズが小さく、見分けられる**。**つまり `coldhard` の身体は前より「よく見分けたうえで」定住している。** **定住は決めかねた結果ではなく、決めた結果だった**——**案の前半（タイ崩しが定住を作っている）は、測定に支持されない。**

**(3) 副産物のほうが大きい。** **効用式に足した項は、評価ノイズより大きくなければ何も動かさない。** **この project が何度も踏んできた「規則は発火するのに行動が変わらない」**（段階35 の危険の信念、段階55a、段階86 の寒さ、段階58 の湧きの偏り）**の、一般的な説明がこれである可能性が高い。** **新しい項を足すときは、その大きさを `choiceGap` の 6.85 と並べて見ること。**

## 2026-09-20 「寒さは定住を強いる」の理由を取り違えていた——移動費ではなく、速さが売られていた

**ユーザの問い「なぜ寒さは定住を強いる？」から。** **同じ日に書いた「寒さが強いと動くことが高くつくので、身体は動かなくなる」は誤り**——**`ChillDrain` は移動の費用ではなく、その場に居ることの体力目減り**で、移動費には1つも触っていない。

**2つの対立仮説を潰して、3つ目が残った。**

**(1) 個体数が減ったからではない。** **`scarce`（食料を絞って個体数を 143.8 → 89.0 に落とす）で `settled` は 0.44 → 0.46**（+0.02 ± 0.04）。**人口が半分近くなっても定住は動かない。** **`coldhard` は人口73.4 で 0.56** なので、**混み具合では説明できない。**

**(2) 若い身体が短い履歴で「定住」と読まれているからでもない。** **`coldhard` の世界はむしろ年寄り**（`age` 5.00 → 6.47、`maturity` 0.68 → 0.83）。**長く生きている身体が、より少ない地域にいる。**

**(3) 残ったのは選択圧だった。** **3つが揃って動いている**:

| | baseline | cold | coldhard | 対の差（coldhard） |
|---|---:|---:|---:|---:|
| `starveRate` | 0.41 | 0.83 | 1.91 | **+1.50 \*\*** |
| **`shSpeed`（予算に占める速さ）** | 0.21 | 0.21 | **0.19** | **−0.03 \*\*** |
| **`regionsSeen`（一生に立つ地域数）** | 5.89 | 5.74 | **5.12** | **−0.77 \*\*\*** |
| `settled` | 0.44 | 0.44 | 0.56 | +0.12 \*\* |

**筋はこう**: **寒さは体力を削る**（飢えが5倍近く）→ **速さが割に合わなくなる**（速く動いても寒さは減らず、体力だけ要る）→ **速さの遺伝子が売られる** → **一生に立つ地域が減る**（長生きなのに5.89→5.12）→ **直近1000tickを1区画で過ごす身体が増える。**

**つまり寒さは身体を縛りつけているのではなく、世界が「動かない身体」を選抜している。** **定住は1つの身体の判断ではなく、数世代の選択の結果だった。**

**これは7番の一文の書き直しにも効く**——**「防寒着は寒冷地で動けるようにする」なら、測るべきは `settled` ではなく `shSpeed` と `regionsSeen`**。**防寒着が速さを買い戻させるかどうかが問い。**

## 2026-09-20 気候を地域から切り離した（決定#135）——粒度は絵が決める。そして「細かいほど効く」は逆だった

**ユーザの指定**: 「**地域とは別のレイヤーにするほうがいい。地域は広くなりすぎる可能性がある。特に初期ステージは地域を少なくすることで難易度を簡単にする予定。**」

**気候を地域に置いた理由（#114・段階85）は「この世界が場所について学んで伝える仕組みは全部地域に乗っている」だった。** **段階86 がその前提を潰していた**——**身体が地域について持つ信念は豊かさ・行きにくさ・危険の3本で、天気はどれでもない。天気を学ぶものも伝えるものも、この世界には1つも無い。**

## 2026-09-20 防寒着は買われない——3つ目の梃子も外れた（1400回渡って1回売れる）

**`coatbite`（殺す寒さ・全部の飾り物が防ぐ・値段とコインあり）、24シード × 20000tick、1実行あたり**:

|---|---:|

### 2つの梃子を試して、両方外れた

**(1) 希少にする**（`coatrare`＝防ぐ飾り物を10分の1に）。**「2820着を92体で分けているから2着目が無価値なのだ」という読み。** **外れ**——**売買は 1.79 → 0.04**（25実行に1回）。**余剰は 0.92 → 0.44 に減ったが、買い手は現れず、身につけている割合が 0.70 → 0.22 に落ちて個体数が 92.0 → 52.9 に崩れた**。**希少にすると、市場ができるのではなく、ただ凍死する。**

**(2) 贈与に代価を付ける**（`coatpriced`＝`GiftPriced`）。**外れ**——**贈与 3292 → 2386、売買 2.33 → 1.42。どちらも減る。** **段階84d（贈与 662 → 64、売買不動）と段階88（贈与 −878 \*\*\*、売買 −0.80 \*\*\*）に続いて3度目**で、**毎回同じ形**: **値段を付けると交換が売買に化けるのではなく、交換そのものが消える。**

**越えるべき数値がこれで決まった**: **`coatsSold` 1.79 と `sales` 2.33**。**材料を入れて、ここが桁で動かなければ、防寒具を商品にする案そのものを閉じる。**
